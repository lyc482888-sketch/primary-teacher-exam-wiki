## 🚀 瀏覽與使用方式

### 方式一：線上網頁瀏覽（GitHub Pages）
若本專案已在 GitHub 開啟 **GitHub Pages**，可直接透過瀏覽器在任何電腦、平板或手機上隨時開啟複習：
- 網址格式：`https://<您的GitHub帳號>.github.io/<專案儲存庫名稱>/`

### 方式二：本機直接開啟（完全離線支援）
1. 直接按兩下開啟專案根目錄的 `index.html`。
2. 或按兩下執行 `start_localhost.bat` 啟動本機伺服器。
3. 全文資料已離線打包，**絕無任何 CORS 跨域限制**，搜尋與切換秒開。

## 📂 目錄結構
```text
.
├── index.html                 # 知識庫視覺化 Web 入口首頁（支援離線搜尋、分類、彈窗閱讀）
├── index.md                   # 知識庫全站 Markdown 導航總索引
├── log.md                     # 操作日誌與知識累積軌跡
├── sync_notes.ps1             # 筆記自動同步腳本（更新 data/notes.js）
├── data/                      # 打包好的筆記 JSON 資料
├── raw/                       # 原始讀書筆記與 OCR 文字檔存檔
├── assets/                    # 圖表與投影片素材
└── wiki/                      # 長效編譯筆記庫
    ├── scholars/              # 人物與教育學者專頁
    ├── theories/              # 核心理論與學派專頁
    ├── curriculum/            # 課程與教學法專頁
    ├── administration/        # 行政與法規專頁
    ├── comparisons/           # 跨概念橫向對照矩陣
    ├── exam_traps/            # 歷屆高頻計算題與秒殺題眼庫
    └── slides/                # Marp 簡報與互動 HTML 投影片
```
