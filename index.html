💡 知識庫使用與 GitHub 發布指引

✨ 如何新增其他筆記文件？

  1. 直接在 wiki/ 對應的分類資料夾中新增 Markdown 檔案（如 wiki/scholars/新學者.md）。
  2. 檔案頂部建議包含 YAML 標頭（可包含 title、category、tags、last_updated）。
  3. 在專案資料夾右鍵點選或於 PowerShell 執行： 
    powershell .\sync_notes.ps1
    腳本會自動掃描並更新 data/notes.js，即刻於本頁展示！

🚀 如何部署到 GitHub Pages？

  1. 在專案根目錄將所有檔案推送到您的 GitHub Repository： 
    git add .
git commit -m "feat: 更新個人筆記庫入口網站"
git push origin main
  2. 到 GitHub 倉庫的 Settings ➔ Pages。
  3. 在 Branch 選擇 main，資料夾選擇 / (root)，按下 Save。
  4. 幾秒鐘後，您的筆記整理庫就會在 https://<你的帳號>.github.io/<倉庫名>/ 永久免費上線！
