## 第 1~9 頁：測驗基本概念、測量量尺、信度理論與測量標準誤

### 一、 測驗、測量、評定、評量、評鑑
- **測量（Measurement）**：透過測量工具，用數字描述個人特質或所測事物屬性。特徵：不涉及價值判斷。實施：檢核表、問卷、量身高。
- **測驗（Test）**：對於具代表性的樣本進行針對個人特質的系統性程序。特徵：強調客觀性。實施：智力測驗、性向測驗。
- **評定**：蒐集、統整和解釋訊息，幫老師做決定的歷程。實施：教師收集訊息所使用的各種方法。
- **評量（Assessment）**：根據一項標準，對所測量到的數量做價值的判斷。教師蒐集、整合與詮釋學生所有學習表現，以擬定適當教學決定。特徵：要進行價值判斷。實施：真實評量、實作評量。
- **評鑑（Evaluation）**：經由鑑定、判斷的過程，據以檢討得失，力求革新進步。特徵：要進行價值判斷。實施：形成性、總結性、安置性、診斷性評鑑。

### 二、 測驗的發展史
1. 1905 年比奈（Binet）受託發展「比西量表」，為「智力測驗之父」。
2. 1879 年馮德（Wundt）在德國創立第一個心理實驗室，奠定測驗程序標準化基礎。
3. 英國高爾登（Galton）致力個別差異研究，提供測驗資料分析的統計方法。
4. 1890 年卡泰爾（Cattell）首創「心理測驗」一詞。
5. 1904 年桑代克（Thorndike）出版第一部教育測量教科書。

### 三、 學習理論與評量理念
1. **實徵／行為主義觀**：知即聯結，強調可觀察行為，重視信度、效度、對知識抽樣、量化標準化紙筆測驗。
2. **理性／認知主義觀**：形成適當知識結構，重視實作與長程表現，多元標準、實作評量與卷宗評量。
3. **社會／歷史主義觀**：知識由互動建構，情境主義，評量學生參與品質與社會互動歷程，自省自評與卷宗評量。

### 四、 四種測量量尺（Stevens）
1. **名義／類別量尺（Nominal / Categorical）**：無數學屬性，單純分類或標示身分（如性別男1女2、背號）。
2. **順序／次序量尺（Ordinal）**：具大小順序與次序性（A>B>C），單位不相等，無絕對零點（如名次、百分位數、地震震度）。
3. **等距量尺（Interval）**：具相等單位（A-B=B-C），可加減但不可乘除，**無絕對零點（零為人為約定）**（如溫度攝氏、智商 IQ）。
4. **比率量尺（Ratio）**：具等距所有特質，且**具有絕對零點（真實零）**，可進行加減乘除（如身高、體重、所得、年齡、時間）。

### 五、 信度（Reliability）
1. **定義**：測驗結果的一致性、穩定性與可靠性。
2. **古典測驗理論真分數模型**：
   - 實得分數 X = 真正分數 T + 誤差分數 E
   - 總變異數 Sx² = St² + Se²
   - 信度 rxx = St² / Sx²（真正變異佔總變異之比例）。
   - 信度係數範圍介於 0.00 ~ 1.00，無負值。
3. **測量誤差分類**：
   - **系統誤差（偏誤）**：以固定、一致方式影響分數（如學習、成長、題目偏難），不影響信度。
   - **隨機誤差（非系統誤差）**：身心狀況、噪音、疲勞、猜測等無規則變化，**直接降低信度**。
4. **信度影響因素**：
   - 測驗題數愈多，信度愈高（可藉斯布校正公式修正）。
   - 受試者異質性愈大（分數全距愈廣），信度愈高。
   - 題目難度適中（P 值接近 0.50），變異數最大，信度愈高。
   - 評分愈客觀，信度愈高。
5. **常模參照信度類型**：
   - **重測信度（Test-Retest）**：同份測驗隔一段時間施測兩次，考驗跨時間穩定性。誤差來源：時間抽樣。
   - **複本信度（Alternate-Form）**：同一批學生施測兩份等值複本，考驗內容與時間穩定性。誤差來源：內容抽樣與時間抽樣。
   - **評分者信度（Scorer Reliability）**：不同評分者評分之一致性。兩人評分採 Spearman 等級相關；三人以上採 Kendall 和諧係數（W）。誤差來源：評分者誤差。
   - **內部一致性信度（Internal Consistency）**：單次施測即可估計：
     - *折半信度（Split-Half）*：題數隨機拆半計算相關，再以斯布公式（Spearman-Brown Formula: rxx = 2rh / (1 + rh)）校正還原全測驗信度。誤差來源：內容抽樣。
     - *庫李信度（KR20, KR21）*：適用於「二元計分（對或錯）」之客觀題。誤差來源：內容抽樣與內容異質。
     - *克隆巴赫 α 係數（Cronbach's α）*：適用於「多元計分（如李克特五點量表）」量表。
6. **標準參照信度類型**：
   - **百分比一致性（PA）**：前後兩次分類決定一致人數比例。
   - **Cohen's Kappa 係數（κ）**：扣除機遇猜測後之一致性指標。
7. **測量標準誤（SEM, Standard Error of Measurement）**：
   - 公式：`SEM = Sx × √(1 - rxx)`
   - 解釋個人分數的可信區間：
     - 68% 信賴區間：實得分數 ± 1 SEM
     - 95% 信賴區間：實得分數 ± 1.96 SEM（實務約 ± 2 SEM）
     - 99% 信賴區間：實得分數 ± 2.58 SEM
   - 信度愈高，標準誤愈小；信度等於 1 時，SEM = 0。

## 第 10~18 頁：效度理論、內外在效度與信效度關係

### 一、 效度（Validity）
1. **定義**：測驗能確實測量到其所欲測量特質或功能的程度。效度是測驗最重要的特徵。
2. **總變異分割**：`Sx² = Sco² + Ssp² + Se²`（共同變異 + 獨特變異 + 誤差變異）。效度為共同因素變異佔總變異之比例。
3. **效度四大類型**：
   - **內容效度（Content Validity）**：試題取樣是否具代表性，能否涵蓋教學目標與教材。
     - 考驗工具：**雙向細目表（Table of Specifications）**。
     - 表面效度（Face Validity）：受試者外觀第一印象，非技術性指標。
     - 現金效度（Cash Validity）：商業測驗銷量，非技術性指標。
   - **效標關聯效度（Criterion-Related Validity）**：測驗分數與外在效標之相關程度。
     - **預測效度（Predictive Validity）**：測驗用以預測未來表現（如大學學測預測大一成績）。效標在未來取得。
     - **同時效度（Concurrent Validity）**：測驗與目前既有效標之相關（如新編智力測驗與魏氏量表之相關）。
     - **預期值表（Expectancy Table）**：直欄為預測變項，橫欄為效標變項之二維機率矩陣。
     - 效標污染（Criterion Contamination）：評分者預先知曉測驗成績，導致效標評分產生偏見高相關。
   - **構念／建構效度（Construct Validity）**：測驗能以心理學理論構念加以解釋的程度。
     - **聚斂效度（Convergent Validity）**：不同方法測量相同構念，應具高相關。
     - **區辨效度（Discriminant Validity）**：相同方法測量不同構念，應具低相關。
     - 考驗方法：因素分析、多特質多方法矩陣（MTMM，Campbell & Fiske）。
   - **後果效度（Consequential Validity，Messick 1989）**：測驗使用所帶來的實際社會後果與價值涵意。
4. **信度與效度之關係**：
   - **信度是效度的必要條件，但非充分條件**。
   - 有效度必定有信度；有信度不一定有效度。
   - 信度低，效度一定低；效度高，信度一定高。
   - **效度係數最大值不超過信度係數的平方根**（`Validity <= √Reliability`）。

### 二、 實驗研究之內在效度與外在效度
1. **內在效度（Internal Validity）—— 可信度**：自變項對依變項造成的真實影響程度，能否確立因果關係。
   - **十二大威脅**：
     1. 歷史／同時事件（History）：實驗期間發生外部特殊事件。
     2. 成熟（Maturation）：受試者身心自然成長疲憊。
     3. 測驗效應（Testing）：前測練習使後測敏感或進步。
     4. 工具變化（Instrumentation）：評分者標準鬆緊改變或儀器磨損。
     5. 統計迴歸（Statistical Regression）：極端組選樣在後測有向平均數靠攏的傾向。
     6. 選樣偏差（Selection）：實驗組與控制組起點不均等。
     7. 樣本亡佚（Mortality）：受試者中途退出導致偏差。
     8. 選樣與成熟交互作用。
     9. **強亨利效應（John Henry Effect）**：控制組受試者不甘示弱，激發超常努力競爭。
     10. 處理擴散（Diffusion of Treatment）：兩組接觸交流使實驗處理外溢。
     11. 實驗者偏見（Experimenter Bias）：研究者期待影響客觀判定。
     12. 統計結論效度缺失。
2. **外部效度（External Validity）—— 可推論性／可轉換性**：
   - **母體效度（Population Validity）**：推論至母群體的程度。
   - **生態效度（Ecological Validity）**：推論至其他環境情境的程度。
   - 威脅：**霍桑效應（Hawthorne Effect）**（受試者因被關注而表現改變）、新奇效應、實驗情境人工化。

## 第 19~23 頁：常模、標準分數轉換與分數解釋

### 一、 常模（Norms）
- **常模定義**：標準化樣本在測驗上所得之平均數與分數分布狀態，用以解釋個人分數之相對地位（常模參照）。
- **發展性常模**：年齡常模（心齡 MA）、年級常模（GE，Grade Equivalent）。
- **組內常模**：
  1. **百分等級（PR, Percentile Rank）**：團體中分數低於該生的人數百分比。公式：`PR = 100 - (100R - 50) / N`。屬順序量尺，中央密集、兩極分散，不可直接加減。
  2. **標準分數（Standard Scores）**：
     - **Z 分數**：`Z = (X - M) / S`，平均數為 0，標準差為 1。
     - **T 分數**：`T = 10Z + 50`，平均數為 50，標準差為 10。
     - **魏氏智商（Wechsler IQ）**：`IQ = 100 + 15Z`，平均數為 100，標準差為 15。
     - **斯比智商（Stanford-Binet IQ）**：`IQ = 100 + 16Z`，平均數為 100，標準差為 16。
     - **標準九（Stanine）**：將常態分配劃分為 9 等分，平均數為 5，標準差為 2。
     - **AGCT 美國陸軍普通分類測驗**：`AGCT = 20Z + 100`。

### 二、 常態分配與偏態分配
- **常態分配（Normal Distribution）**：對稱鐘形，**平均數 ＝ 中位數 ＝ 眾數（Mean = Median = Mode）**。
- **正偏態（偏右偏態，Positive Skew）**：少數極高分將尾巴往右拉長，考題太難（低分多）。
  - **大小順序：眾數 < 中位數 < 平均數（Mode < Mdn < Mean）**。
- **負偏態（偏左偏態，Negative Skew）**：少數極低分將尾巴往左拉長，考題太容易（高分多）。
  - **大小順序：平均數 < 中位數 < 眾數（Mean < Mdn < Mode）**。

## 第 24~32 頁：各式教育測驗、智力測驗與人格測驗

### 一、 教育測驗分類體系
- **按目標**：認知測驗（智力/性向/成就）、情意測驗（態度/人格/興趣）、動作技能測驗。
- **按反應型態**：
  - **最大表現測驗（Maximum Performance）**：測驗個人最佳能力，有對錯，受動機能力影響（智力/性向/成就）。
  - **典型表現測驗（Typical Performance）**：測驗日常生活正常表現，無對錯標準，易受偽飾作假影響（人格/態度/興趣）。
- **按參照架構**：常模參照（NRT） vs 效標參照（CRT）。

### 二、 智力測驗
1. **發展歷程**：
   - 高爾頓生理計量法（感覺敏銳度）。
   - 比奈比西量表（心理年齡 MA）。
   - 推孟斯比量表（比率智商 `IQ = (MA / CA) × 100`）。
   - 魏克斯勒魏氏量表（離差智商 `IQ = 100 + 15Z`）。
2. **斯比量表 vs 魏氏量表對照**：
   - 斯比量表：第一二版為年齡量表，三四版為點量表；偏重兒童（14歲以下）；提供單一智商；標準差 16。
   - 魏氏量表：全面採用點量表；提供語文智商（VIQ）、作業智商（PIQ）與全量表智商（FSIQ）；標準差 15。

### 三、 性向測驗 vs 成就測驗對照
- **性向測驗**：測量未來學習潛能，取材廣泛，教學前施測，著重預測效度與區分效度。
- **成就測驗**：測量過去已習得之知識技能，內容局限特定教材，教學後施測，著重內容效度。

### 四、 人格測驗與情意測驗
1. **自陳量表（Self-Report）**：
   - 編製方法：經驗法效標計分法（MMPI、CPI）、因素分析法（16PF）、理論法（EPPS 愛德華興趣量表）。
   - 防偽飾技術：強迫選擇式項目、測謊量表（Lie Scale）、隱蔽測驗目的。
2. **情境測驗（Situational Test）**：哈特宋誠實測驗、莫里諾社會關係測驗、情境壓力測驗。
3. **投射測驗（Projective Test）**：曖昧非結構化刺激，探測潛意識：
   - 聯想法：榮格文字聯想、羅夏墨漬測驗。
   - 構造法：莫雷主題統覺測驗（TAT）。
   - 完成法：羅特未完成語句測驗（RISB）。
   - 選組法：宋迪測驗（Szondi）。
   - 表達法：畫人測驗、畫樹測驗、動態屋樹人（K-H-T-P）。

## 第 33~45 頁：教學評量分類、變通與替代評量（實作、檔案、動態、生態）

### 一、 教學評量功能分類（四向度矩陣）
1. **安置性評量（Placement）**：教學前施測，確定學生起點行為與舊經驗精熟度，做分班編組決定。
2. **形成性評量（Formative）**：教學進行中實施，提供即時回饋，診斷學習缺失，作為修正教學進度與方法的依據（隨堂測驗、單元小考）。
3. **診斷性評量（Diagnostic）**：教學中或學期初，針對學生**持續且重複出現的學習困難**深入診斷病因，作為補救教學依據。
4. **總結性評量（Summative）**：教學單元或學期結束時實施，評定學業成就等第，判斷教學目標達成程度（期末考、畢業會考）。

### 二、 常模參照（NRT） vs 效標參照（CRT）評量
- **NRT**：與他人比較，重相對地位，試題難度中等（P 接近 0.50），排除極易極難題，題目鑑別度高，適用於選拔分班。
- **CRT**：與既定標準比較，重個人精熟度，試題難度配合教學目標，不排除極易題，適用於檢定證照與補救教學。

### 三、 變通與替代性評量（Alternative Assessment）
1. **真實評量（Authentic Assessment）**：在真實生活情境中，評量學生應用知識解決實際問題的操作表現。
2. **實作評量（Performance Assessment）**：
   - 要求學生動手執行指定任務，兼顧歷程與結果。
   - 類型：紙筆實作、實物辨認測驗（物件測驗）、結構化實作、模擬實作、作品樣本。
   - 評分方式：整體式評分（Holistic） vs 分析式評分（Analytic，評分規程 Rubrics）。
3. **檔案評量／卷宗評量（Portfolio Assessment）**：
   - 有系統、長時間連續蒐集學生作品，展現學習歷程、努力、進步與自我省思。
   - 類型：展示卷宗（Showcase）、描述性卷宗、評估性卷宗、進步卷宗（Progress）。
4. **動態評量（Dynamic Assessment）**：
   - 依據維高斯基（Vygotsky）近側發展區（ZPD），在評量中融入教學介入。
   - 歷程：**前測 ➔ 中間教學引導（鷹架介入） ➔ 後測**，評估學習潛能與認知可塑性。
   - Embretson 空間推理心理計量模式。
5. **生態評量（Ecological Assessment）**：
   - 評估身心障礙或特殊需求學童在自然生態環境（學校、家庭、社區、職場）中的適應功能與技能落差。

## 第 46~52 頁：情意評量、社會計量技術與課程本位評量

### 一、 情意評量技術
1. **軼事記錄法（Anecdotal Records）**：記錄自然情境下偶發的特殊具體事實。原則：即時記錄、描述與短評分開、聚焦單一事件、累積多筆後才做推論。
2. **評定量表（Rating Scales）**：數字型、圖示型、敘述圖示型。評定誤差：寬鬆偏誤、嚴苛偏誤、趨中偏誤、月暈效應、邏輯誤差。
3. **檢核表（Checklists）**：二分法判定特質「出現（是）」或「未出現（否）」，不評定品質等級。
4. **語意差別量表（Semantic Differential Scale，Osgood）**：運用兩極形容詞（如好-壞、強-弱、主動-被動）評定對事物的情感認知。

### 二、 莫里諾（Moreno）社會計量法（Sociometry）
- 評量班級團體人際結構與社交地位：
  - **社會計量矩陣**：二維表格記錄相互選擇。
  - **社會關係圖（Sociogram）**：以圖形表示人際網絡（女性圓形、男性三角形、箭頭表示選擇）。
  - **猜是誰技術（Guess-Who Technique）**：提供正負向行為描述句，由同儕提名符合者，診斷邊緣孤立或受歡迎學生。

### 三、 課程本位評量（CBA, Curriculum-Based Assessment）
- 以實際課堂教學內容為基礎的非標準化頻繁評量，監控學生進展與教學成效，常用於資源班特教與補救教學。
- 三大模式：標準參照 CBA、正確性基礎 CBA、流暢性基礎 CBA（單位時間內正確反應次數）。

## 第 53~62 頁：教學目標分類學與各題型命題原則

### 一、 布魯姆（Bloom）教學目標分類學
1. **認知領域（1956 舊版 vs 2001 Anderson 新版）**：
   - 1956 舊版：知識 ➔ 理解 ➔ 應用 ➔ 分析 ➔ 綜合 ➔ 評鑑。
   - 2001 修訂版二維向度：
     - **知識向度**：事實知識、概念知識、程序知識、後設認知知識。
     - **認知歷程向度**：記憶 ➔ 了解 ➔ 應用 ➔ 分析 ➔ 評鑑 ➔ 創造。
2. **情意領域（Krathwohl）五層次**：
   - 接受（注意） ➔ 反應 ➔ 價值判斷 ➔ 價值的組織 ➔ 價值的性格化（品格形成）。
3. **動作技能領域（Simpson）七層次**：
   - 知覺 ➔ 心向（準備） ➔ 模仿 ➔ 機械練習 ➔ 複雜反應 ➔ 技能調適 ➔ 創作。
4. **艾斯納（Eisner）表意目標**：強調學生在情境中開放、獨特的體驗與感受，非預設特定具體行為結果。
5. **梅傑（Mager）行為目標五要素（ABCD 原則）**：
   - 對象（Audience）、行為（Behavior，可觀察動詞）、情境條件（Condition）、表現標準（Degree）。

### 二、 各類紙筆題型命題與評分原則
1. **雙向細目表**：橫軸為教學目標（Bloom認知層次），縱軸為教材內容單元，交叉分配題數與權重配分。
2. **是非題**：避免雙重否定、避免含有絕對字眼（總是、絕不）、對與錯題數相當且隨機排列。
3. **選擇題**：題幹涵蓋主要問題、選項長度相當且避免重疊、**避免「以上皆是」與「以上皆非」**、誘答選項具似真性。
4. **配合題**：項目性質相同、問題項與反應項數量不相等（反應項多 2~3 個以防消去法猜測）、印在同一頁。
5. **申論題**：測量高層次認知能力；**評分原則**：預擬評分規準、評分前後一致、一次評閱一題、兩位評分者獨立評分、匿名閱卷。

## 第 63~73 頁：試題分析、教育統計與研究法

### 一、 試題分析（Item Analysis）
1. **常模參照分組法**：總分排序，最高分 27% 為高分組（H），最低分 27% 為低分組（L）。
2. **試題難度指數（P, Difficulty Index）**：
   - 公式：`P = (PH + PL) / 2` 或 `P = R / N`
   - P 值介於 0.00 ~ 1.00；**P 值愈大表示試題愈容易，P 值愈小愈難**。
   - 優良試題難度範圍：0.40 ~ 0.70，**平均難度以 0.50 最佳**。
3. **試題鑑別度指數（D, Discrimination Index）**：
   - 公式：`D = PH - PL`
   - D 值介於 -1.00 ~ +1.00；**D 值愈高鑑別力愈好**。
   - 鑑別度標準：**D >= 0.40 優良；0.30 ~ 0.39 良好；0.20 ~ 0.29 尚可；D < 0.20 劣質須淘汰；D 為負值必為反向題須立即修改或刪除**。
4. **難度與鑑別度之關係**：試題難度適中（P=0.50）時，分數變異最大，鑑別力達到最高峰。
5. **誘答力分析**：優良誘答選項應吸引低分組選答人數顯著多於高分組；若高分組選答多於低分組或無人選答，該誘答項須修訂。

### 二、 教育統計基礎
1. **差異檢定**：
   - **t 考驗**：比較兩個平均數之差異（獨立樣本 t 考驗 vs 成對樣本 t 考驗）。
   - **ANOVA 變異數分析（F 考驗）**：比較三個以上平均數之差異。
   - **ANCOVA 共變數分析**：統計控制前測干擾變項，排除組間初始差異。
2. **相關係數**：
   - **Pearson 積差相關**：等距或比率變數，常態雙變量線性相關。
   - **Spearman 等級相關**：順序變數，兩組評分者排序。
   - **Kendall 和諧係數（W）**：三位以上評分者等級一致性。
3. **卡方考驗（χ²）**：適用於類別資料（次數、百分比）之適合度檢定與獨立性檢定。
4. **抽樣方法**：
   - 簡單隨機抽樣：均等與獨立機率。
   - 系統抽樣：按名冊每隔 k 個元素抽取一個。
   - **分層隨機抽樣**：**組間異質、組內同質**，最具母體代表性。
   - **叢集抽樣**：**組間同質、組內異質**，以完整群體（如整班、整校）為抽樣單位。
5. **研究方法**：實驗法（因果推論）、調查法、參與觀察法、內容分析法、民族誌。
6. **戈德門（Goldman）資料解釋四類型**：描述型（現狀） ➔ 追溯型（成因） ➔ 預測型（未來） ➔ 評鑑型（價值判斷與決策）。
