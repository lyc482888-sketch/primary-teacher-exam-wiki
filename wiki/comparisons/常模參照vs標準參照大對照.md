# 常模參照 vs 標準參照大對照

## 一句話定位
> 常模參照（NRT）重在「人比人」，比較個人在團體中的相對排名；標準參照（CRT，又稱效標參照）重在「人比標準」，檢定個人是否精熟教學目標門檻。

---

## 一、 常模參照（NRT） vs 效標／標準參照（CRT）十大維度全景對照矩陣

| 比較維度 | 常模參照測驗（NRT, Norm-Referenced） | 標準／效標參照測驗（CRT, Criterion-Referenced） |
| :--- | :--- | :--- |
| **1. 核心意涵與參照點** | **與他人相互比較**：以標準化常模樣本的團體平均表現為參照點。 | **與既定標準比較**：以預先設定的「行為表現規準或精熟門檻（Cut-off Score）」為參照點。 |
| **2. 主要評量目的** | **甄選選拔、區分優劣、排名篩選**（看誰在團體中名列前茅）。 | **評估教學成效、診斷個別學習弱點、證照資格檢定、擬定補救教學**。 |
| **3. 試題難度（P）取向** | 追求難度適中，**平均難度以 `P = 0.50` 最理想**；刻意排除「全員答對（P=1.0）」與「全員答錯（P=0）」的試題。 | **完全配合教學目標**；若教學目標全體都應學會，即使試題極端容易（P=0.95 以上）也**絕不排除**。 |
| **4. 試題鑑別度（D）要求** | **高度強調高鑑別度**（D 愈高愈好，D >= 0.40），必須能有效拉開不同考生的能力差距。 | **不刻意追求高鑑別度**；只要題目能準確區分「精熟者」與「非精熟者」即可。 |
| **5. 分數呈現與解釋** | **相對地位指標**：百分等級（PR）、直線標準分數（Z、T）、離差智商（IQ）、標準九。 | **絕對達成水準**：答對百分比（如 80 分及格）、精熟／非精熟（Pass / Fail）、等級標準（A++、A、B、C）。 |
| **6. 試題取樣範疇** | **取樣廣泛但深入度較淺**：為了涵蓋廣大領域，試題涵蓋面寬，但每個特定概念題數較少。 | **取樣範圍界定具體且深入**：針對特定教學目標深度出題，題數集中以確實檢驗是否精熟。 |
| **7. 測驗信度檢驗方法** | **古典相關係數**：重測信度、複本信度、內部一致性（KR-20, Cronbach's α）、折半斯布公式。 | **領域分類一致性指標**：百分比一致性（PA）、Cohen's Kappa 係數（κ）、Livingston k² 係數。 |
| **8. 最核心強調之效度** | **構念效度、預測效度、區別效度**。 | **內容效度、領域參照效度**（試題能否完整涵蓋既定教學目標）。 |
| **9. 國小現場典型實例** | 國小縣市語文競賽甄選、校內資優班鑑定測驗、國小教師甄試初試。 | 國小每課生字聽寫測驗、游泳 25 公尺換氣檢定、國民體適能達標測驗、教師資格考試（教檢）。 |
| **10. 缺點與實務限制** | 無法確知學生「實際學會了什麼」，只能知道「比別人強還是弱」；易引發惡性競爭。 | 合格門檻（標準點）的訂定容易帶有主觀性；無法區分同樣通過及格線學生的優異程度。 |

## 二、 常態分配與標準分數在兩者中的角色

| 測驗類型 | 對分數分配型態的假定與期待 | 教學哲學觀點 |
| :--- | :--- | :--- |
| **常模參照（NRT）** | 期待學生成績呈現**常態分配（Normal Distribution）**，分數呈現鐘形對稱，中間多兩頭少。 | **遺傳決定論／個別差異觀**：認為智力與才能天生分歧，教育功能在於客觀篩選與分流。 |
| **標準參照（CRT）** | 期待學生成績呈現**負偏態（Negative Skew）**，絕大多數學生透過充分時間與個別化指導皆達到精熟。 | **樂觀主義／精熟學習觀（Bloom）**：只要提供適當的時間與教學條件，95% 以上學生都能達到精熟。 |

## 三、 國小教甄初試高頻題眼與秒殺辨析

1. **「教檢」vs「教甄」核心差異**：
   - **教師資格考試（教檢） ➔ 【效標／標準參照（CRT）】**：達到平均 60 分及格門檻即獲合格教師證書。
   - **教師甄試（教甄） ➔ 【常模參照（NRT）】**：依各縣市開缺缺額，按總分高低擇優錄取錄取率僅 2%~5% 的考生。
2. **題目：「王老師編製了一份國語期中考，發現第一題全班 30 人全部答對，王老師應該如何處置？」**
   - 若為**標準參照測驗**（評估教學目標是否達成） ➔ **保留此題**（證明教學成功，全員達成目標）。
   - 若為**常模參照測驗**（選拔分班） ➔ **刪除或修改此題**（P=1.00，D=0.00，無任何鑑別力）。
