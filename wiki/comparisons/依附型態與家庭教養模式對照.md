# 依附型態與家庭教養模式對照

## 一句話定位
> 整合安斯沃思陌生情境四大依附型態、鮑姆林德與馬寇比家庭教養四象限矩陣，以及奧蘇貝爾衛星化親子關係模式，為國小初試教育心理學與輔導原理常客題型。

---

## 壹、 安斯沃思（Mary Ainsworth）四大依附型態雙軸大矩陣

> 依據個體對**「自我評價（自尊與自我效能）」**與對**「他人評價（他人信任度）」**的內在工作模式（Internal Working Model），建構 2×2 矩陣：

| 自我評價 ＼ 他人評價 | **看別人：好**<br>(高度信任他人、渴望親密關係) | **看別人：不好**<br>(不信任他人、防衛抽離疏遠) |
| :---: | :--- | :--- |
| **看自己：好**<br>(自尊自信、正向自我價值) | **【安全型依附】(Secure)**<br>- **幼兒行為**：母親在場安心探索，重聚時主動迎向安撫並迅速平靜<br>- **成年人際**：信任親密、情感有彈性、能適度依賴亦能獨立自主 | **【逃避型依附】(Avoidant)**<br>- **幼兒行為**：母親在場或離去皆無所謂，重聚時眼神刻意迴避冷漠<br>- **成年人際**：防衛性過度獨立、壓抑情感、拒絕依賴他人或被依賴 |
| **看自己：不好**<br>(缺乏自信、強烈無價值感) | **【抗拒／矛盾型】(Resistant / Ambivalent)**<br>- **幼兒行為**：母親在場仍焦慮，重聚時既渴望親近又憤怒抗拒推打<br>- **成年人際**：過度焦慮黏人、極度恐懼被拋棄、在關係中愛恨交加 | **【紊亂／混亂型】(Disorganized)**<br>- **幼兒行為**：反應矛盾錯亂無連貫策略（如倒退走向母親或突然僵硬）<br>- **成年人際**：人際關係極端動盪不穩、自我破碎、既渴望愛又極端恐懼 |

| 依附型態名稱 | 自我與他人評價 | 陌生情境中幼兒反應 | 母親／主要照顧者之教養特徵 | 成年後之人際與親密關係樣態 |
| :--- | :--- | :--- | :--- | :--- |
| **安全型依附**<br>(Secure) | **看自己：好**<br>**看別人：好** | 母親在場時積極探索；分離時適度悲傷抗議；**母親重聚時熱情迎接並迅速平撫安心**。 | 具備高敏感度、迅速且準確回應嬰兒需求、溫暖親切、前後一致。 | 情感成熟有彈性、具備基本信任感、能適度依賴亦能獨立、能享受深度親密。 |
| **抗拒／矛盾型**<br>(Resistant /<br>Ambivalent) | **看自己：不好**<br>**看別人：好** | 母親在場時依然緊繃；分離時極度崩潰哭鬧；**母親重聚時既渴望親近又憤怒抗拒踢打（愛恨交加）**。 | 照顧品質欠佳、情緒化教養、回應前後不一致（視大人自身心情忽冷忽熱）。 | 情感高度飢渴焦慮、極度害怕被拋棄、過度黏人依賴、疑神疑鬼、缺乏安全感。 |
| **逃避型依附**<br>(Avoidant) | **看自己：好**<br>**看別人：不好** | 母親在場或離去皆顯得無所謂；**母親重聚時眼神刻意迴避、轉身忽視不理**；待陌生人與母親無異。 | 對嬰兒缺乏耐性、排斥身體接觸、常以冷漠或拒絕態度要求幼兒過早獨立。 | 表面極度獨立、情緒壓抑抽離、拒絕依賴他人或被他人依賴、傾向用事物取代情感交流。 |
| **紊亂／混亂型**<br>(Disorganized) | **看自己：不好**<br>**看別人：不好** | 行為矛盾錯亂無連貫策略（如走向母親時倒退著走、突然趴在地上或僵硬凝視虛空）。 | 照顧者本身具有嚴重身心創傷、嚴重家暴虐待、酗酒吸毒，既是依附源頭亦是恐懼來源。 | 人際極端不穩定、徘徊於極度逃避與強烈恐慌之間、自我破碎、極難建立長期信任。 |

## 貳、 鮑姆林德（Baumrind）與馬寇比（Maccoby）四大家庭教養型態

> 依據父母的**「回應度（溫暖、接納、情感支持）」**與**「要求度（控制、規範、期望標準）」**兩大維度，交織出四大經典教養型態：

| 要求度（控制）＼ 回應度（接納） | **回應度／接納度：低**<br>(情感冷漠、缺乏溝通支持) | **回應度／接納度：高**<br>(溫暖接納、積極回應溝通) |
| :---: | :--- | :--- |
| **要求度／控制度：高**<br>(嚴密規範、界限分明) | **【獨斷專制型】(Authoritarian)**<br>- **管教特徵**：高要求、低回應；訴諸權威與體罰，不解釋理由<br>- **子女特質**：被動盲從、焦慮退縮、缺乏自信、易生敵對 | **【權威開明型】(Authoritative) ★ 最優模式**<br>- **管教特徵**：高要求、高回應；理性說理、尊重協商、適度獨立<br>- **子女特質**：自我肯定高、獨立自主、自律負責、社會適應佳 |
| **要求度／控制度：低**<br>(缺乏常規、放任自流) | **【忽視冷漠型】(Neglectful / Uninvolved)**<br>- **管教特徵**：低要求、低回應；漠不關心、放任棄管、不給予愛與規範<br>- **子女特質**：自尊低落、孤獨疏離、自我控制力差、易涉偏差犯罪 | **【寬容溺愛型】(Permissive / Indulgent)**<br>- **管教特徵**：低要求、高回應；過度放任、有求必應、缺乏行為設限<br>- **子女特質**：自我中心、缺乏挫折容忍力、生活散漫、衝動任性 |

| 教養型態名稱 | 回應度（接納） | 要求度（控制） | 父母教養行為特徵 | 培育之青少年性格特質（國小教甄高頻題眼） |
| :--- | :--- | :--- | :--- | :--- |
| **權威開明型**<br>(Authoritative)<br>★ 最優教養型態 | **高（溫暖）** | **高（合理要求）** | 充滿愛心與接納，訂定明確且合理之生活規範，**重視雙向溝通、願意協商並詳述規則理由**。 | **自我肯定高、獨立自主、自我控制力佳、社會適應良好、學業成就佳**。 |
| **獨斷專制型**<br>(Authoritarian) | **低（嚴苛冷漠）** | **高（極端控制）** | 強調無條件服從與權威，**訴諸體罰與嚴苛禁令，極少向子女解釋理由，忽視自主需求**。 | 缺乏自信、被動盲從、焦慮退縮、對權威懷有深層怨恨，易在背後爆發敵對行為。 |
| **寬容溺愛型**<br>(Permissive / Indulgent) | **高（過度接納）** | **低（缺乏規範）** | 給予過度自由與物質滿足，**不設防線、不立規矩、缺乏行為要求，對不當行為妥協退讓**。 | **自我中心、缺乏挫折容忍力、自我約束力差、生活散漫、人際衝動**。 |
| **忽視冷漠型**<br>(Neglectful / Uninvolved) | **低（漠不關心）** | **低（放任棄管）** | 父母忙於自身事務或生活挫敗，**對子女身心需求極端漠視，不提供愛亦不施加管教**。 | **自尊低落、孤獨疏離、容易逃家輟學、參與幫派犯罪、心理健康風險最高**。 |

## 參、 奧蘇貝爾（David Ausubel）衛星化親子關係理論

> 奧蘇貝爾將兒童青少年的身心成熟歷程比喻為天體行星運行的**「衛星化理論（Satellization Theory）」**：

### 一、 衛星化（Satellization）
- 幼童承認父母是不可或缺的「太陽核心」，自身如同「衛星」般環繞父母運轉，依附父母並完全接受父母的社會化價值。
- **正向功能**：兒童從中內化父母的價值觀與良心道德意識，學會延遲滿足與遵守規則，獲得扎實的安全感與自尊。

### 二、 脫離衛星化（Desatellization）
- 進入青少年期，個體渴望擺脫以父母為中心的天體軌道，邁向獨立成人的漸進歷程。
- **三大脫離衛星化機轉**：
  1. **重新衛星化（Resatellization）**：青少年將原本對父母的依附轉移至**「同儕團體或偶像」**身上，在同儕群體中尋求認同與歸屬。
  2. **試著贏得個人地位（Status Striving）**：透過學業、運動、才藝等自我表現爭取社會地位，證明個人實力。
  3. **自主探索與任務解決（Exploratory Competence）**：透過面對困難、解決獨立生活任務，驗證自我能力，逐漸不再依附家庭。

### 三、 非衛星化（Non-satellization）的病態型態
- 幼年期未曾建立起健康的衛星化依附關係：
  - **低度價值化（拒絕型）**：父母視孩子為沉重負擔與累贅，冷酷拒絕，導致個案終生缺乏基本信任感。
  - **過度價值化（溺愛型）**：孩子被奉為全家中心，孩子擁有操控父母的病態特權，長大後形成自戀與無法適應社會規範。
