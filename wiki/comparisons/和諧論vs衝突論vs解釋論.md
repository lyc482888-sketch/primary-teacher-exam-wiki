# 和諧論 vs. 衝突論 vs. 解釋論（三大教育社會學派典全解析）

> 本對照表是國小教甄教育社會學初試選擇題最核心的辨析工具。各大考題均圍繞在三大學派的立場與概念切換。

---

## 核心維度橫向對照表

| 比較維度 | 和諧理論（[[結構功能論]]） | [[衝突理論]]（新馬克思主義） | 解釋論（[[符號互動論]]） |
| :--- | :--- | :--- | :--- |
| **研究取向與範疇** | **鉅觀研究**（Macroscopic）<br>關注國家、整體社會結構與制度 | **鉅觀研究**（Macroscopic）<br>關注階級結構、政經權力分配 | **微觀研究**（Microscopic）<br>關注班級教室日常生活、人際互動 |
| **對社會的本質假定** | 社會如**生物有機體**，各部門各司其職、分工合作、注重穩定平衡 | 社會充滿**利益衝突與權力壓迫**，社會常態是對立、強制與不平等 | 社會是**人際動態互動建構**的產物，透過符號、磋商與詮釋維持 |
| **社會變遷的原動力** | **協調與調適**<br>體制內漸進改良、追求穩定中求進步 | **衝突與階級鬥爭**<br>變遷是常態，透過革命或抗爭推翻壓迫 | **互動與意義的重新詮釋**<br>行動者動態磋商、持續重新定義情境 |
| **學校教育的主要功能** | **社會化**（傳承共同規範）與<br>**選擇**（依才分流安置階層） | **再製不平等**（維護統治階級利益，透過符應與文化資本進行階級複製） | **意義建構與角色互動**（師生日常角力、印象整飾、標籤賦予） |
| **課程與知識的屬性** | **客觀中立、普及共享**<br>是人類文化菁華與共同道德規範 | **具意識形態、階級偏見**<br>代表統治階層的利益，屬「符號暴力」 | **社會建構產物、非價值中立**<br>知識是師生在課堂互動中詮釋生成的 |
| **代表學者** | [[涂爾幹]]（教育社會學之父）<br>[[帕森士]]（班級社會體系）<br>墨頓（顯性/隱性功能）<br>戴維斯與穆爾（階層化功能） | [[馬克思]]（歷史唯物論）<br>鮑爾斯與金提斯（符應原則）<br>[[布迪爾]]（文化資本再製）<br>[[伯恩斯坦]]（語言符碼）<br>威里斯（反學校文化/文化創生） | 米德（自我發展理論）<br>庫里（鏡中自我）<br>高夫曼（戲劇論/印象整飾）<br>貝克（標籤理論）<br>葛芬柯（俗民方法論） |
| **主要研究方法** | 實證主義、量化統計、科學客觀調查 | 歷史分析、辯證法、批判意識型態分析 | 質性研究、參與觀察、微觀民族誌、訪談 |
| **人性假設** | 人性本善（或可透過社會化完善） | 傾向揭露體制之惡與結構壓迫 | 人具主動能動性、創造性與反省能力 |

## 國小教甄選擇題破題關鍵字庫

> 🎯 **秒殺決策指南**：教甄初試看到題幹中的特定線索關鍵字，直接對應核心派典！

| 題幹關鍵字線索（考題出現這些字眼） | 毫不猶豫秒選派典 | 核心代表學者與必考考點 |
| :--- | :--- | :--- |
| 🔹 **結構穩定、各司其職、漸進改良、社會化與選擇、價值共識、功能互惠** | 🟢 **【和諧論 / 結構功能論】** | [[涂爾幹]]（有機連帶）、[[帕森士]]（班級社會體系兩大功能、AGIL 模型）、墨頓（顯性/隱性功能） |
| 🔹 **階級複製、資本符應、意識形態國家機器、文化霸權、象徵暴力、反學校文化** | 🔴 **【衝突理論 / 再製學派】** | [[馬克思]]（歷史唯物論）、鮑爾斯（符應原則）、[[布迪爾]]（文化資本與慣習）、威里斯（反學校文化） |
| 🔹 **微觀課堂、前台後台、鏡中自我、語言符碼、標籤互動、日常磋商、俗民方法** | 🟣 **【解釋論 / 符號互動論】** | 庫里（鏡中自我）、米德（自我發展）、高夫曼（戲劇論）、貝克（標籤理論）、[[伯恩斯坦]]（語言符碼） |

### 💡 實戰破題三秒判讀法
- **題幹若提及「維持社會穩定、通識教育培養共同信念、各部門互惠調適」** ➔ 毫不猶豫選 **和諧論（結構功能論）**。
- **題幹若提及「學校在複製資本主義工廠的階層服從、優勢階層透過文化資本保持特權、勞工子弟反學校文化」** ➔ 毫不猶豫選 **衝突論（再製理論）**。
- **題幹若提及「師生在課堂互動中互相試探底線、老師貼標籤影響學生自我概念、教室生活俗民誌」** ➔ 毫不猶豫選 **解釋論（符號互動論）**。
