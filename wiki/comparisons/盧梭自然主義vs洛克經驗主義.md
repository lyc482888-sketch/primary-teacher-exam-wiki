# 盧梭自然主義 vs. 洛克經驗主義（啟蒙時代兩大教育思潮橫向辨析）

## 一句話定位
> 歐洲啟蒙時代兩大劃時代思想家——盧梭的「順應自然天性」與洛克的「後天白板形塑」，構成現代兒童教育思想的兩大互競張力。

---

## 核心橫向對照表

| 比較維度 | [[盧梭|盧梭（Jean-Jacques Rousseau）]] | [[洛克|洛克（John Locke）]] |
| :--- | :--- | :--- |
| **代表學派** | **自然主義（Naturalism）** | **經驗主義（Empiricism）** |
| **代表巨著** | 《**愛彌兒**》（Émile，1762） | 《**教育漫話**》（Some Thoughts Concerning Education，1693） |
| **人性基本假定** | **人性天賦純善**<br>「出自造物主之手都是完好的，一到人手裡全變壞了」 | **白板說（Tabula Rasa）**<br>心如潔白平滑之板，無任何先天觀念，全憑後天雕琢印刻 |
| **教育的核心目標** | 培養不受世俗虛偽污染、身心和諧自由的**「自然人」** | 培養具有健全身體、理性自制力與品格的**「英國紳士」** |
| **教育方法與進路** | **消極教育（Negative Education）**<br>12歲前不灌輸道德說教，順應感官與體力自然開展 | **形式訓練說（Formal Discipline）**<br>鍛鍊心靈官能（如推理、記憶、專注），著重良好習慣塑造 |
| **紀律與懲罰觀** | **自然後果懲罰（Natural Punishment）**<br>讓兒童直接承受自身行為的物理客觀制約（如吹冷風） | **說理、名譽感與羞恥心**<br>反對肉體體罰，主張運用同儕名譽激發榮譽感與自我節制 |
| **知識與書本態度** | **反對過早閱讀死背**<br>15歲前唯一的讀物是《魯賓遜漂流記》，在生活中探究 | **強調實用與理智訓練**<br>循序漸進學習文法、歷史、外語、會計與旅行 |
| **身心健康觀** | 順應自然野性體能，赤足奔跑 | **健全的身體造就健全的心靈**（冷水浴、耐磨訓練） |

## 國小教甄歷屆考點與陷阱
- **名著名言秒殺**：
  - 「白板說、形式訓練、健全的心智寓於健全的身體、紳士教育」➔ 必選 **洛克（Locke）**。
  - 「出自造物主、消極教育、自然懲罰、教育界哥白尼、愛彌兒」➔ 必選 **盧梭（Rousseau）**。
- **高頻陷阱題眼**：
  - 題幹描述「讓孩子打破玻璃自己承受寒冷以自省」➔ 此為盧梭的**自然結果懲罰**，絕非洛克的說理名譽！
  - 題幹問「心靈官能訓練勝過實質內容學習」➔ 這是洛克的**形式訓練說**。
