# 行政法一般原則與學校法治實務指南

## 一句話定位
> 現代學校行政主管與教師在班級管教、學生獎懲、聘任審議與法制行政中必須嚴格遵守的法治底線。

---

## 核心行政法一般原則對照表

| 法治原則名稱 | 核心法律內涵與定義 | 國小校園現場法治實務應用 |
| :--- | :--- | :--- |
| **法律優位原則<br>（消極依法行政）** | 行政作為**「不得牴觸」**現行上位法律與憲法（法律優越於行政命令）。 | 學校校規或班規若牴觸《教師法》或《教育基本法》（如訂定體罰班規），該班規**自始無效**。 |
| **法律保留原則<br>（積極依法行政）** | 凡涉及**限制人民基本權利**（如學生受教權、教師工作權）之事項，必須有**「法律明文規定或明確授權」**方得為之。 | 學校欲開除學生學籍或給予重大懲戒，必須有中央法律明文依據，不得單憑校長個人口頭決定。 |
| **比例原則<br>（過度禁止原則）** | 行政手段不得逾越達成目的之必要限度，拿捏適當，**「切忌用大砲打小鳥」**。涵蓋適當性、必要性與衡量性。 | 學生偶發忘記帶作業，教師處以課後留置 10 分鐘指導，若處以罰站一整天或禁止下課一週即違反比例原則。 |
| **正當法律程序<br>（Due Process）** | 行政機關作成不利處分前，應給予當事人**「陳述意見的機會」**、知情權與救濟途徑。 | 學校召開學生獎懲委員會或性平會議前，應正式書面通知家長與學生，並給予充分答辯陳述時間。 |
| **明確性原則** | 法令內容、構成要件與法律效果必須清楚明白，使一般大眾**「可得理解、可得預見」**。 | 班規制定不可寫籠統模糊字眼（如「言行不檢者重罰」），應具體明定何種違規對應何種處置。 |
| **信賴保護原則** | 人民因信賴國家行政法規而有所安排者，其正當利益應予保護，**法令不得朝令夕改或不利溯及既往**。 | 學校制定之畢業或獎學金標準，不得在學期末突然無預警提高門檻，導致原已達標學生權益受損。 |
| **誠實信用原則<br>（誠信原則）** | 行政機關與人民行使權利、履行義務時，應恪守誠信、信守承諾，不得出爾反爾。 | 行政承諾給予教師參與研習之公差假，事後無故推翻否決即違反誠信原則。 |
| **平等原則** | **「等者等之，不等者不等之」**，非有正當合理理由，不得為差別待遇；允許**「積極的差別待遇」**。 | 對偏鄉學校、身心障礙學童提供特殊資源與補償教育（符合實質垂直平等）。 |

## 壹、 比例原則三大子原則（初試超高頻必考）

比例原則又稱「禁止過當原則」，行政作為必須**同時通過以下三項檢驗**：

1. **適當性原則（合目的性原則）**：
   - 採取的行政手段必須**「有助於目的之達成」**。
   - 例：為了維護校園安寧，命令禁止在走廊奔跑，此手段確實有助於防範碰撞受傷（通過適當性）。
2. **必要性原則（侵害最小原則 / 最少損害原則）**：
   - 在所有同樣能達成目的的有效手段中，必須選擇**「對人民或學生權益損害最輕微者」**。
   - 例：為了制止學生上課聊天，口頭提醒即可達成目的，卻直接沒收學生文具或體罰，即違反必要性原則。
3. **狹義比例原則（衡量性原則 / 比例性原則）**：
   - 手段所造成的損害，與所欲達成的公益目的之間，**「不得顯失均衡」**。
   - 利益與損害必須處於合理適當的比例。

## 貳、 學校行政倫理的四大層面

教育行政人員處理校務與衝突時，應本於道德主體實踐四種倫理思維：
1. **專業倫理（Professional Ethics）**：所作所為服膺教育專業本質，保障學童最佳受教福祉。
2. **正義倫理（Justice Ethics）**：堅持公平正義、權力合理行使、弱勢補償與資源均衡分配。
3. **關懷倫理（Care Ethics）**：諾丁絲（Noddings）倡導，真誠關照師生的人性情感、同理心與個別脆弱處境。
4. **批判倫理（Critique Ethics）**：勇於反省組織中的不當特權、科層壓迫與社會再製現象，仗義執言。

## 國小教甄歷屆考點與陷阱
- **定義秒殺對照**：
  - 行政不得牴觸法律 ➔ **法律優位原則（消極）**。
  - 限制人民權利須有法律授權 ➔ **法律保留原則（積極）**。
  - 不能用大砲打小鳥、侵害最小 ➔ **比例原則之必要性原則**。
  - 處分前給予當事人陳述意見機會 ➔ **正當法律程序**。
  - 法令不可任意朝令夕改 ➔ **信賴保護原則**。
