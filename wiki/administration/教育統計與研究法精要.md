# 教育統計與研究法精要

## 一句話定位
> 教育統計提供量化資料的推論工具（t 考驗、ANOVA、ANCOVA、卡方），抽樣方法決定研究推論範圍（分層 vs 叢集），而行動研究則是國小現場教師解決問題、結合理論與實務的核心研究途徑。

---

## 一、 推論統計差異檢定法對照矩陣

在教育實證研究中，選擇適當的統計檢定方法取決於「自變項組數」與「依變項量尺特性」：

| 統計方法名稱 | 適用情境與變項條件 | 虛無假設（H0）範例 | 國小教育研究實務實例 | 教甄破題關鍵字 |
| :--- | :--- | :--- | :--- | :--- |
| **獨立樣本 t 考驗**<br>(Independent t-test) | 比較**兩個獨立互斥群體**在連續變項（等距/比率）上的平均數差異。 | 兩組母體平均數相等：<br>`μ1 = μ2` | 比較國小男生與女生在數學成就測驗上的平均分數差異。 | 兩組、獨立、平均數差異、男女比較 |
| **成對／相依樣本 t 考驗**<br>(Paired t-test) | 比較**同一群受試者在兩次施測**（如前測 vs 後測）或成對配對組的平均數差異。 | 差值之母體平均數為 0：<br>`μD = 0` | 評估某實驗教學法對同一班學童實施前與實施後的國語閱讀表現差異。 | 同一組、前測與後測、前後比較 |
| **單因子變異數分析**<br>(One-Way ANOVA / F 考驗) | 比較**三個或三個以上獨立群體**在單一依變項上的平均數差異。 | 各組母體平均數全相等：<br>`μ1 = μ2 = μ3` | 比較國小低、中、高三個年級在校園幸福感上的平均數差異。 | 三組以上、平均數比較、F考驗、事後比較（Scheffé） |
| **共變數分析**<br>(ANCOVA) | 當無法完全隨機分派（如現成常規班級實驗），藉由統計方法**排除前測初始能力（共變項 Covariate）的干擾影響**後，再比較各組後測平均數。 | 排除前測能力後，各教學法後測調整後平均數無差異。 | 兩班學生初始英文程度不同，欲比較「平板教學」與「傳統教學」成效，**將前測成績作為共變項予以統計控制**。 | 排除前測差異、控制干擾變項、統計控制、調整後平均數 |
| **卡方適合度考驗**<br>(Chi-Square Goodness-of-Fit) | 檢定**單一類別變項**的實際觀察次數（O）與理論期待次數（E）是否相符。 | 實際觀察分布符合理論分布。 | 檢驗國小學童對四種社團（音樂/體育/美術/科學）的選填偏好是否均等。 | 單一類別、次數百分比、適合度、偏好均等 |
| **卡方獨立性考驗**<br>(Chi-Square Test of Independence) | 檢定**兩個類別變項**之間是否存在關聯性或相互獨立。 | 兩類別變項彼此互相獨立無關。 | 檢驗「學生性別（男/女）」與「是否參加課後照顧班（是/否）」之間有無關聯。 | 兩個類別變項、列聯表、交叉分析、有無關聯 |

## 二、 常用相關係數選用準則

| 相關係數名稱 | 適用變數形態與量尺條件 | 典型應用情境 |
| :--- | :--- | :--- |
| **皮爾森積差相關（Pearson r）** | 兩變項皆為**連續變數（等距或比率量尺）**，且符合雙變量常態分配。 | 國小學童智商（IQ）與數學定期考分數之相關。 |
| **斯皮爾曼等級相關（Spearman ρ）** | 兩變項皆為**順序量尺（名次、等級）**，或未符合常態分配。 | 兩位評審老師對演講比賽名次排序的一致性相關。 |
| **肯德爾和諧係數（Kendall W）** | **三位以上評審者**對同一組受試者之等級評定一致性。 | 5位評審委員對國小科展作品名次之評分一致性信度。 |
| **點二系列相關（Point-Biserial）** | 一變項為**連續變數**，另一變項為**真實二分變數**（如性別男/女、試題對/錯）。 | 計算選擇題單題得分（0分或1分）與測驗總分之相關（鑑別度分析）。 |
| **費氏相關（Phi 相關, φ）** | 兩變項皆為**真實二分名義變數**（2×2 列聯表）。 | 「性別（男/女）」與「是否通過英檢（是/否）」之相關。 |

## 三、 四大機率抽樣方法辨析（必考重點）

抽樣方法的代表性直接決定研究的**外在效度（母體推論力）**：

| 抽樣方法 | 抽取程序與核心概念 | 特徵與組間／組內結構（必考口訣） | 國小教育現場實務 |
| :--- | :--- | :--- | :--- |
| **簡單隨機抽樣**<br>(Simple Random) | 母群體中每個個體被抽中的**機率均等且彼此獨立**（如抽籤、亂數表）。 | 樣本代表性客觀，但母群龐大時名冊取得困難。 | 全校1000名學生抽籤抽出100人。 |
| **系統抽樣**<br>(Systematic Sampling) | 先確定抽樣間隔 `k = N / n`，隨機決定第一個起點後，**每隔 k 個元素抽取一個**。 | 簡便快速，但若母體名冊存在隱藏週期性循環，將導致嚴重偏差。 | 按學號名冊每隔 10 號抽取一人。 |
| **分層隨機抽樣**<br>(Stratified Random) | 先將母群體依特定背景變項（年級、性別、城鄉）分成若干互斥互補的「層」，再依各層人數比例進行隨機抽樣。 | **★ 口訣：【組間異質、組內同質】**<br>最具母體代表性，能確保少數族群按比例被抽中。 | 將全縣小學依「山區、市區、海線」分三層，各層按學生比例隨機抽樣。 |
| **叢集抽樣／部落抽樣**<br>(Cluster Sampling) | 不是以「個人」為抽樣單位，而是將母體劃分為許多完整「群體/單位」，**隨機抽取若干整個群體（整組全測）**。 | **★ 口訣：【組間同質、組內異質】**<br>大幅節省人力與交通成本，但抽樣誤差較大。 | 隨機抽取全縣「5 所小學的全體六年級班級」進行施測。 |

## 四、 國小現場核心研究法：行動研究（Action Research）

行動研究是當代國小教師落實自主專業成長的重要機制：

| 核心維度 | 行動研究的本質與規範 |
| :--- | :--- |
| **研究倡導者** | **柯勒（Lewin）** 首創概念；**柯瑞（Corey）** 將其引入教育領域。 |
| **核心哲學** | **「為行動而研究、在行動中研究、由行動者研究」**（Research for action, in action, by actors）。 |
| **研究主體** | **教師即研究者（Teacher as Researcher）**。 |
| **研究目的** | **解決教學現場的具體實際問題、改善教育實踐**，而非追求普遍化的學術理論建構。 |
| **研究歷程** | 螺旋式循環歷程：**計畫（Plan） ➔ 行動（Act） ➔ 觀察（Observe） ➔ 省思（Reflect） ➔ 修正再計畫**。 |

## 五、 戈德門（Goldman）測驗資料解釋四類型

測驗施測完畢後，教師或輔導人員向學生及家長解釋資料時的四種層次：

1. **描述型解釋（Descriptive）**：告知學生測驗分數的**現狀事實**（如「你的魏氏智商是 110，在同齡中屬於中上」）。
2. **追溯型解釋（Genetic）**：探究分數形成的**過去歷史與成因**（如「數學成績不理想，是因為三年級分數乘除法基礎未扎實」）。
3. **預測型解釋（Predictive）**：依據性向與測驗數據推估**未來的發展可能**（如「依你的空間性向分數，未來選讀理工科系表現良好的機率高達 80%」）。
4. **評鑑型解釋（Evaluative）**：結合個人價值觀與社會需求，協助當事人做出**具體的行動與決策選擇**。

## 六、 國小教甄歷屆必考題眼與口訣庫

1. **分層抽樣 vs 叢集抽樣 絕殺口訣**：
   - **分層抽樣 ➔ 【組間異質、組內同質】**（層與層不同，層內很像）。
   - **叢集抽樣 ➔ 【組間同質、組內異質】**（班與班差不多，班內各形各色）。
2. **共變數分析（ANCOVA）**：
   - 題幹出現「無法隨機分派學生」、「將前測成績視為干擾變項加以統計控制」➔ **秒選共變數分析（ANCOVA）**。
3. **行動研究**：
   - 「國小教師在日常課堂中為解決班級經營突發問題所進行的自主循環研究」➔ **必選行動研究**。
