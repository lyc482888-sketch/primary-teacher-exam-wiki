# 教育測驗與評量核心考點手帳
### 國小教師甄試教育專業科目速成手冊
**資料來源**：Sharon 73 頁筆記精華提煉  
**核心考點**：心理計量、信度與效度、測量標準誤、常模參照 vs 標準參照、試題分析

---

# 一、 古典測驗信度理論與誤差來源

- **真分數模型（CTT）**：
  - 實得分數 $X = T + E$（真正分數 + 誤差分數）
  - 總變異數 $S_x^2 = S_t^2 + S_e^2$
  - 信度定義：$r_{xx} = S_t^2 / S_x^2$（真正分數變異佔總變異之比例，介於 0.00~1.00）
- **信度估計方法與誤差**：
  - **重測信度**：跨時間穩定性 ➔ **時間抽樣誤差**。
  - **複本信度**：等值性與穩定性 ➔ **內容抽樣＋時間抽樣誤差**。
  - **折半信度**：內部一致性 ➔ **內容抽樣誤差**（須用斯布公式校正回全測驗）。
  - **庫李信度（KR-20, KR-21）**：**限二元計分（對/錯）客觀題**。
  - **Cronbach α 係數**：**適用多元計分（李克特 5 點量表、問卷）**。
  - **評分者信度**：2位用 Spearman 等級相關；3位以上用 Kendall 和諧係數（W）。

# 二、 測驗效度四大面向與內外在效度

- **測驗效度四大面向**：
  - **內容效度**：試題取樣代表性。成就測驗首選，工具為**雙向細目表**。
  - **效標關聯效度**：同時效度（當下）、預測效度（未來，性向測驗首重）。
  - **構念效度**：符合心理學理論。聚斂效度（相關高）與區辨效度（相關低）。
  - **後果效度**：Messick 提出，評估測驗對社會之長遠衝擊。
- **信度與效度關係**：
  - 信度是效度的必要條件，非充分條件。
  - 效度係數上限等於信度的平方根（$Validity \le \sqrt{Reliability}$）。
- **實驗研究效度威脅**：
  - **強亨利效應**：控制組不甘示弱超常努力（內在效度威脅）。
  - **霍桑效應**：受試者因被關注觀察而表現提升（外在生態效度威脅）。
  - **統計迴歸**：極端組後測必然向平均數靠攏。

# 三、 測量標準誤（SEM）與 95% 信賴區間

- **SEM 公式**：
  $$SEM = S_x \times \sqrt{1 - r_{xx}}$$
  - $S_x$：測驗實得分數標準差；$r_{xx}$：測驗信度。
  - 信度愈高 ➔ SEM 愈小 ➔ 分數估計愈精準。
  - 當信度 $r_{xx} = 1.00$ 時，$SEM = 0$。
- **真實分數信賴區間**：
  - 68% 信賴區間：$X \pm 1(SEM)$
  - 95% 信賴區間：$X \pm 1.96(SEM)$（考題速解常概算為 $X \pm 2(SEM)$）
  - 99% 信賴區間：$X \pm 2.58(SEM)$
- **解題實例**：
  - 若標準差 $S_x = 10$，信度 $r_{xx} = 0.84$，小明實得 70 分。
  - $SEM = 10 \times \sqrt{1 - 0.84} = 10 \times 0.4 = 4$ 分。
  - 95% 信賴區間：$70 \pm 2(4) = [62分, 78分]$。

# 四、 常模參照（NRT） vs 標準參照（CRT）

| 比較維度 | 常模參照測驗（NRT） | 標準／效標參照測驗（CRT） |
| :--- | :--- | :--- |
| **參照點** | **與他人比較**（常模平均表現） | **與既定標準比較**（精熟門檻） |
| **主要目的** | 甄選選拔、排名篩選（人比人） | 評估教學成效、診斷補救（人比標準） |
| **試題難度** | 平均難度 $P \approx 0.50$ 最佳；排除極易極難題 | 配合教學目標；即使 $P=0.99$ 極易亦保留 |
| **鑑別度要求** | 強烈追求高鑑別度（$D \ge 0.40$） | 不刻意追求高 D，能區分精熟即可 |
| **分數轉換** | PR值、Z、T、離差 IQ、標準九 | 及格/不及格、通過率、等第（A/B/C） |
| **期望分配** | 常態分配（對稱鐘形） | 負偏態（精熟學習，多數人達標高分） |
| **教甄實例** | **國小教甄初試**、資優鑑定 | **教師資格考試（教檢）**、體適能檢定 |

# 五、 標準分數轉換體系與偏態大小順序

- **標準分數換算公式**：
  - $Z = (X - M) / S$（平均 0，標準差 1）
  - $T = 10Z + 50$（平均 50，標準差 10）
  - 魏氏 $IQ = 15Z + 100$（平均 100，標準差 15）
  - 標準九 $= 2Z + 5$（平均 5，標準差 2）
- **偏態分配大小順序（必考秒殺口訣）**：
  - **中位數（Median）永遠在中間！**
  - **常態分配**：平均數 ＝ 中位數 ＝ 眾數
  - **正偏態（右偏態，考題難，低分多）**：
    $$\text{眾數} < \text{中位數} < \text{平均數}$$
  - **負偏態（左偏態，考題易，高分多）**：
    $$\text{平均數} < \text{中位數} < \text{眾數}$$

# 六、 布魯姆教學目標分類學與行為目標

- **Bloom 2001 修訂版二維架構**：
  - **知識向度（名詞）**：事實知識、概念知識、程序知識、後設認知知識。
  - **認知歷程向度（動詞）**：
    1. 記憶 ➔ 2. 了解 ➔ 3. 應用 ➔ 4. 分析 ➔ 5. 評鑑 ➔ **6. 創造（最高層）**
- **情意領域五層次（Krathwohl）**：
  - 接受 ➔ 反應 ➔ 價值判斷 ➔ 價值的組織 ➔ 價值的性格化（品格形成）。
- **目標撰寫模式**：
  - **梅傑（Mager）行為目標 ABCD**：對象、外顯行為動詞、情境條件、評分標準。
  - **艾斯納（Eisner）表意目標**：強調情境中開放、獨特的自發體驗，無標準答案。

# 七、 多元替代評量光譜

- **評量時機四大功能**：
  - **安置性評量**：教學前，評估起點行為與先備知識，決定分班。
  - **形成性評量**：教學中，提供即時回饋，隨堂修正教學進度。
  - **診斷性評量**：針對學生**持續且反覆的嚴重學習障礙**，找出病因補救教學。
  - **總結性評量**：教學結束或期末，評定學業成就等第。
- **替代評量類型**：
  - **真實評量**：真實生活情境中解決問題。
  - **實作評量**：動手操作，兼顧歷程與結果，採 Rubrics 評分規程。
  - **檔案評量**：長期系統蒐集代表作，**核心靈魂為學生自我省思**。
  - **動態評量**：基於 Vygotsky ZPD，採「前測 ➔ 介入教學 ➔ 後測」，評量學習潛能。

# 八、 紙筆測驗命題原則與試題分析

- **雙向細目表**：教學目標（Bloom認知歷程） × 教材內容單元，確保**內容效度**。
- **試題分析指標（Kelly 27% 高低分組法）**：
  - **難度指數（P）**：$P = (P_H + P_L) / 2$
    - $P$ 愈大愈容易，$P$ 愈小愈難！適中區間為 $0.40 \le P \le 0.70$。
  - **鑑別度指數（D）**：$D = P_H - P_L$
    - $D \ge 0.40$：優良；$0.30 \sim 0.39$：良好；$D < 0.20$：劣質需淘汰。
    - **$D$ 為負值（反向題）**：低分組答對多於高分組，通常答案公佈錯誤或試題具嚴重誤導，**必須立即修改或刪除**！
- **誘答力分析**：
  - 優良誘答項：低分組選答人數顯著多於高分組（$P_L > P_H$）。
  - 致命瑕疵：若高分組選答多於低分組（$P_H > P_L$），誘答項具反向誤導，須重寫。

# 九、 教育統計推論檢定與抽樣方法

- **差異檢定選用**：
  - **獨立樣本 t 考驗**：兩組獨立群體平均數比較（如男女數學成績）。
  - **成對樣本 t 考驗**：同一組學生前後測平均數比較。
  - **單因子變異數分析（ANOVA / F 考驗）**：三組以上平均數差異比較。
  - **共變數分析（ANCOVA）**：常規班級無法隨機分派，**將前測視為干擾共變項予以統計控制**。
  - **卡方考驗（$\chi^2$）**：類別資料（次數、百分比）之適合度與獨立性考驗。
- **抽樣方法口訣秒殺**：
  - **分層隨機抽樣**：**【組間異質、組內同質】**，依族群比例抽樣，代表性最佳。
  - **叢集抽樣**：**【組間同質、組內異質】**，以整班、整校為抽樣單位。
  - **行動研究（Lewin, Corey）**：教師即研究者，在現場解決問題，螺旋反思循環。

# 十、 國小教甄測驗評量秒殺題眼總整理

1. **雙向細目表 ➔ 【內容效度】**（成就測驗核心）。
2. **鑑別度 D 出現負值 ➔ 【答案錯誤或反向誤導，應刪除】**。
3. **效度上限 ➔ 【信度係數的平方根】**（$r_{xy} \le \sqrt{r_{xx}}$）。
4. **前測 ➔ 介入指導（鷹架） ➔ 後測 ➔ 【動態評量、Vygotsky ZPD】**。
5. **學生自我反思、縱貫作品集 ➔ 【檔案卷宗評量】**。
6. **受試者知被觀察表現提升 ➔ 【霍桑效應】**；**控制組不甘示弱 ➔ 【強亨利效應】**。
7. **極端選樣後測向中間靠攏 ➔ 【統計迴歸】**。
8. **字寫得漂亮就認為頭腦聰明 ➔ 【邏輯誤差】**；**一好百好 ➔ 【月暈效應】**。
9. **分層抽樣 ➔ 【組間異質、組內同質】**；**叢集抽樣 ➔ 【組間同質、組內異質】**。
