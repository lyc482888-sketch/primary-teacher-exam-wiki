信度篇 ➔ 一致性與穩定性
古典測驗信度類型與誤差來源大對照
信度是效度的「必要非充分條件」，隨機誤差直接戕害信度
必考指標
信度類型 施測方式與次數 考驗之一致性特質 核心誤差來源（考題必考） 重要公式與注意事項
重測信度 同一份測驗，間隔時間施測 2 次 跨時間之穩定性 時間抽樣誤差（身心變化、記憶練習） 間隔太短有記憶效應；太長受成熟學習影響。
複本信度 施測等值兩份複本（同時或間隔） 同時：等值性；間隔：穩定等值 同時：內容抽樣；間隔：內容＋時間抽樣 最嚴格的信度估計，但編製真正等值複本極難。
折半信度 單次施測，奇偶數題目拆成兩半 題項抽樣之內部一致性 內容抽樣誤差 ★ 必須以斯布公式（2rh / 1+rh）校正回全測驗。
庫李信度 單次施測，KR-20 / KR-21 題目同質性與內部一致性 內容抽樣與內容異質性 ★ 僅限「二元計分（對/錯、1分/0分）」客觀題！
Cronbach α 單次施測多元計分題目 問卷量表之內部一致性 內容抽樣與內容異質性 ★ 廣泛適用於李克特 5 點量表、多元給分題。
評分者信度 多位評審獨立對同一作答評分 評分者間主觀客觀度 評分者個人偏見、寬嚴標準漂移 2位評分者用 Spearman 相關；3位以上用 Kendall W。
⚠️ 誤差辨析口訣： 系統誤差（偏誤）（如量尺固定加5分）➔ 不影響信度，但戕害效度； 隨機誤差（噪音、身體不適、猜測）➔ 直接降低信度！
效度篇 ➔ 測驗的最關鍵特徵
四大效度類型與實驗研究內外在威脅
效度上限等於信度的平方根（Validity ≤ √Reliability）
實驗設計題眼
🎯 測驗效度四大面向
  • 內容效度：試題抽樣的代表性。成就測驗首選，依據雙向細目表審查。
  • 效標關聯效度：與外在標準之相關。
    ➔ 同時效度（效標當下取得）；
    ➔ 預測效度（性向測驗首重，效標在未來取得）。
    ➔ 效標污染：評分者預先看過測驗分帶有先入偏見。
  • 構念效度：符合理論心理架構程度。
    ➔ 聚斂效度（不同法測同特質要高相關）；
    ➔ 區辨效度（同法測不同特質要低相關）。工具：因素分析、MTMM 矩陣。
  • 後果效度：Messick 提出，評估測驗帶來的社會長遠衝擊。
⚡ 內在效度 vs 外在效度高頻陷阱
  • 統計迴歸效應：挑選「極端高分」或「極端低分」受試者，後測必然自然向平均數靠攏！
  • 強亨利效應（John Henry）：控制組不甘示弱，激發超常努力競爭！（內在效度威脅）
  • 霍桑效應（Hawthorne）：受試者因知道自己被特別挑選注視而表現大增！（外在生態效度威脅）
  • 歷史與成熟：外部偶發大事件（歷史） vs 自然身心成長疲勞（成熟）。
  • 樣本亡佚：受試者中途退出破壞隨機均等。
效度與信度數學關係 rxy ≤ √(rxx)
例題速解 信度 0.64 ➔ 效度上限 √0.64 = 0.80
計算篇 ➔ 分數可信區間推估
測量標準誤（SEM）與 95% 信賴區間解題法
信度愈高，SEM 愈小；當信度等於 1 時，SEM = 0
必得 2 分計算題
📐 SEM 核心公式與原理
SEM = Sx × √(1 - rxx)
  • Sx：測驗實得分數的標準差。
  • rxx：測驗的信度係數。
  • 物理意義：個人實得分數圍繞真正分數的變異標準差。
  • 反比關係：信度愈高 ➔ SEM 愈小 ➔ 測驗分數估計愈精準。
🎯 常態分佈三大信賴區間
68% 信賴區間 實得分數 X ± 1(SEM)
95% 信賴區間 實得分數 X ± 1.96(SEM)
★ 教甄計算常概算為 X ± 2(SEM)
99% 信賴區間 實得分數 X ± 2.58(SEM)
🔥 歷屆教甄實戰速解範例
【題目】某國小數學成就測驗標準差為 10 分，信度為 0.84。小明實得 70 分，請問在 95% 信賴水準下，小明的真分數區間為何？
【解題步驟】
1. 算 SEM：SEM = 10 × √(1 - 0.84) = 10 × √0.16 = 10 × 0.4 = 4 分
2. 算 95% CI：70 ± 2 × (4) = 70 ± 8 ➔ 答案秒選 [ 62 分 , 78 分 ]！
體系篇 ➔ NRT vs CRT
常模參照 vs 標準參照（效標參照）全景對照
常模參照看「相對排名（人比人）」，標準參照看「是否精熟（人比標準）」
概念高頻考點
比較向度 常模參照測驗（NRT） 標準／效標參照測驗（CRT）
比較基準 與他人比較（常模團體之平均表現） 與既定標準比較（精熟及格門檻 Cutoff）
主要目的 甄選選拔、排名篩選、劃分優劣 評估教學成效、診斷補救、資格檢定
試題難度取向 平均難度 P ≈ 0.50 最佳；排除全員答對題 配合教學目標；即使 P=0.99 極易也不排除
試題鑑別度要求 高度追求高鑑別度（D 愈高愈好，D ≥ 0.40） 不刻意追求高 D，能區分精熟/未精熟即可
分數轉換型態 PR值、Z分數、T分數、離差智商、標準九 及格/不及格、百分比通過率、等級（A/B/C）
信度檢驗方法 相關係數（重測、折半、α、KR-20） 分類一致性指標（PA、Cohen's Kappa κ）
期望分配型態 常態分配（鐘形對稱，中間多兩極少） 負偏態（精熟學習，多數人達到高分）

統計量尺篇 ➔ Z, T, IQ, PR
標準分數轉換體系與偏態大小順序口訣
中位數永遠在正中間；偏向哪邊，平均數就被極端值往哪邊拖拽！
必背口訣庫
📊 標準分數四大金剛換算表
  • Z 分數：Z = (X - M) / S（平均 0，標準差 1）
  • T 分數：T = 10Z + 50（平均 50，標準差 10）
  • 魏氏 IQ：IQ = 15Z + 100（平均 100，標準差 15）
  • 標準九：Stanine = 2Z + 5（平均 5，標準差 2）
常態分佈百分比： Z=0 (PR 50) ➔ Z=+1 (PR 84) ➔ Z=+2 (PR 98)
⚡ 偏態分配大小順序（教甄秒殺）
偏態種類 試題難易度 大小順序（考題必背）
常態分配 難度適中（P≈0.5） 平均數 ＝ 中位數 ＝ 眾數
正偏態（右偏） 題目太難（低分多） 眾數 < 中位數 < 平均數
尾巴在右，平均數被極端高分拉大！
負偏態（左偏） 題目太易（高分多） 平均數 < 中位數 < 眾數
尾巴在左，平均數被極端低分拉小！
★ 秒殺實例：某次考試「平均數 40，中位數 55，眾數 70」，試問為何種分配？ ➔ 平均數 (40) < 中位數 (55) < 眾數 (70) ➔ 平均數最小，尾巴在左 ➔ 負偏態（偏左偏態），代表題目太容易！
目標篇 ➔ 雙向細目表之魂
Bloom 2001 修訂版二維矩陣與行為目標
由 Anderson 修訂：知識向度（名詞） × 認知歷程向度（動詞）
素養命題準則
🧠 認知歷程向度六層次（由低至高）
  • 1. 記憶（Remember）：提取長效記憶（識別、回憶）。
  • 2. 了解（Understand）：建構意義（詮釋、舉例、分類、摘要、推論、比較、解釋）。
  • 3. 應用（Apply）：在新情境執行程序（執行、實作）。
  • 4. 分析（Analyze）：分解整體探討架構（區辨、組織、歸因）。
  • 5. 評鑑（Evaluate）：依規準做客觀批判（檢查、評論）。
  • 6. 創造（Create）★ 最高層：整合要素產生原創成品（規劃、產生、製作）。
📚 知識向度四向度
  • 事實知識：術語、特定細節（如記住九九乘法）。
  • 概念知識：分類、原則、通則與理論模型。
  • 程序知識：演算法、技術方法、操作步驟（How to do）。
  • 後設認知知識：策略性知識、對自我認知與監控之了解。
🎯 目標撰寫學派對照
  • 梅傑 Mager 行為目標（ABCD 原則）：對象、外顯動詞、情境條件、評分規準。客觀可測。
  • 艾斯納 Eisner 表意目標：注重情境中開放、獨特體驗，不預設標準答案。
評量革新篇 ➔ 素養導向
多元替代評量：真實、實作、卷宗檔案與動態評量
突破紙筆測驗侷限，兼顧歷程、情境脈絡與認知可塑性
現場教學必備
🌍 真實評量
在逼真、真實的生活情境中，評量學生應用知識解決實際問題的整合能力。（如規劃園遊會記帳）。
🛠️ 實作評量
要求學生動手操作或展現實質產出，兼顧歷程與結果。採 Rubrics（評分規程） 確保客觀性。
📁 檔案卷宗評量
長期系統化蒐集學生代表作。靈魂核心是「學生自我省思（Self-reflection）」，分為展示型與進步型。
🚀 動態評量
源自 Vygotsky ZPD。採「前測 ➔ 介入教學 ➔ 後測」三階段，評估學習潛能與可塑性。
🌟 評量時機與功能四大向度速記
安置性評量：教學前施測，評估起點行為與先備知識，決定分班。
形成性評量：教學中進行，提供即時回饋，隨堂修正教學進度。
診斷性評量：針對學生持續且反覆的嚴重學習障礙，找出根本病因以實施補救教學。
總結性評量：教學單元結束或期末，評定學業成就等第，驗收目標。
命題技術篇 ➔ 難度、鑑別度與誘答力
紙筆測驗試題分析與誘答選項判讀準則
Kelly 27% 高低分組法：P 值看難易，D 值看區辨力
實作試卷核心
📐 試題分析兩大核心公式
  • 試題難度（P）：P = (PH + PL) / 2
    ➔ P 愈大愈簡單，P 愈小愈困難！
    ➔ 優良區間：0.40 ≤ P ≤ 0.70，最佳為 0.50。
  • 試題鑑別度（D）：D = PH - PL
    ➔ D ≥ 0.40：極優良試題。
    ➔ 0.30 ≤ D ≤ 0.39：良好試題。
    ➔ D < 0.20：劣質需淘汰。
    ➔ D 為負值（反向題）：答案公佈錯誤或語意反向誤導，必須立即刪除停用！
🕵️ 誘答力分析三原則
  • 原則一：有效誘答項吸引的低分組人數應顯著多於高分組（PL > PH）。
  • 原則二：每個誘答選項都至少要有人選（0人選者等同廢項）。
  • 原則三（致命傷）：若誘答項吸引的高分組居然多於低分組（PH > PL），代表有嚴重邏輯瑕疵，必須重寫！
命題大忌：選擇題切忌使用「以上皆是」與「以上皆非」！
實證研究法篇 ➔ 統計與抽樣
教育統計推論檢定與抽樣方法秒殺庫
掌握方法適用時機，一秒鎖定教甄題目正解
滿分通關
📊 統計檢定方法選用指南
  • 獨立樣本 t 考驗：比較兩組獨立群體平均數（如男女數學成績比較）。
  • 成對樣本 t 考驗：比較同一組學生前後測之平均數差異。
  • 變異數分析（ANOVA / F 考驗）：比較三組以上群體之平均數差異。
  • 共變數分析（ANCOVA）：現成分班無法隨機，將前測成績視為干擾變項（共變項）予以統計控制。
  • 卡方考驗（χ²）：類別變項（次數、百分比）之適合度與獨立性檢定。
🎯 四大抽樣方法秒殺口訣
  • 分層隨機抽樣：
    ➔ 口訣：【組間異質、組內同質】
    依族群、城鄉按比例抽樣，母體代表性最佳！
  • 叢集抽樣（部落抽樣）：
    ➔ 口訣：【組間同質、組內異質】
    以整班、整校為抽樣單位（整組全測），節省成本。
  • 系統抽樣：每隔 k 個元素抽取一個（k = N/n）。
  • 簡單隨機抽樣：抽籤、亂數表，人人機率均等獨立。
🌟 行動研究（Action Research）： 由 Lewin 提出、Corey 引入教育。「為行動而研究、在行動中研究、由行動者研究」；教師即研究者，旨在解決現場實務問題，歷程為螺旋反思循環！
