## 單元一：古希臘三哲核心對照

| 哲人 | 稱號與學派 | 核心思想與方法 | 經典名言 / 著作 |
| :--- | :--- | :--- | :--- |
| **蘇格拉底** | 道德哲學之父<br>西方孔子 | **產婆法（問答法）**<br>（諷刺➔助產➔歸納➔定義） | 「知即德」<br>「未經省察的人生不值得活」 |
| **柏拉圖** | 觀念論之祖 | **洞穴寓言、哲學王**<br>靈魂三分（理性金/意志銀/慾望銅鐵） | 《理想國》<br>阿卡德米學園 |
| **亞里斯多德** | 實在論之祖<br>逍遙學派 | **身心一元論、四因說**<br>德行倫理學、中庸之道、博雅教育 | 萊錫姆學園<br>理智德行 vs 道德德行 |

## 單元二：近代教育學四巨匠

- **康門紐斯（近代教育學之父）**：
  - 《大教育學》（首部系統專書）、《世界圖解》（首部插畫教材）。
  - **泛智論**：「把一切知識教給所有人」；人生四季四級學校（母育、國語、拉丁、大學）。
- **盧梭（自然主義之父、教育界哥白尼）**：
  - 《愛彌兒》；「出自造物主之手都是完好的，一到人手裡全變壞了」。
  - **消極教育**（12歲前）、**自然後果懲罰**（體驗客觀制約）。
- **康德（批判哲學之父）**：
  - 「人是唯一必須受教育的受造物」；「感性無知性則盲，知性無感性則空」。
  - **直言命令（無上命令）** vs **假言命令**；首位大學開講教育學。
- **赫爾巴特（教育學之父、心理學之父）**：
  - 《普通教育學》；以倫理學（定目的）與心理學（定方法）為基石。
  - **統覺論**（統覺團）、**多方面興趣**、**四段教學法（明聯系方）** ➔ 五段教學法。

---

## 單元三：平民教育與現代進步主義

- **裴斯泰洛齊（國民教育之父、小學教育鼻祖）**：
  - **3H 均衡教育**：頭（Head/智）、心（Heart/德，核心）、手（Hand/體技）。
  - 教育心理化與社會化；要素教育（數、形、字）；實物直觀教學。
- **福祿貝爾（幼稚教育之父）**：
  - 創辦第一所**幼稚園（Kindergarten）**；「教育之道無他，唯愛與榜樣而已」。
  - **開展說 / 園丁論**；發明**恩物（Gifts）**；重視遊戲與自動原則。
- **杜威（實用主義大師、進步主義領航人）**：
  - **三大命題**：「教育即生活」、「教育即生長」、「教育即經驗的不斷重組與改造」。
  - **做中學（Learning by doing）**；教育無外在目的；問題教學五步驟。

## 單元四：先秦諸子人性論與教育主張

| 學者 | 人性假定 | 核心教育主張 | 國小教甄題眼線索 |
| :--- | :--- | :--- | :--- |
| **孔子** | 性相近，習相遠 | **有教無類、因材施教、啟發教學** | 不憤不啟不悱不發、四教（文行忠信） |

## 單元五：宋明理學 vs. 心學極速對照

| 辨析維度 | 朱熹（程朱理學） | 王陽明（陸王心學） |
| :--- | :--- | :--- |
| **本體核心** | **性即理**（理客觀存在於外物） | **心即理**（心外無物，良知自足） |
| **修養工夫** | **格物窮理**（由外向內探索） | **致良知**（向內省察擴充） |
| **治學進路** | **道問學**（廣讀經典考據） | **尊德性**（立志直契本心） |
| **知行關係** | **知先行後**（知在先，行在後） | **知行合一**（知是行之始，行是知之成） |
| **兒童教育** | 習《小學》規矩儀節 | 《訓蒙大意》順應嬉遊天性、倡歌詩習禮 |

## 單元六：初試秒殺之父稱號庫

- **教育學之父** ➔ **赫爾巴特**（注意！題目若有「近代」二字則選康門紐斯）
- **近代教育學之父** ➔ **康門紐斯**（著《大教育學》與插畫《世界圖解》）
- **國民教育之父 / 小學教育鼻祖** ➔ **裴斯泰洛齊**（3H 教學）
- **幼稚教育之父** ➔ **福祿貝爾**（幼稚園 Kindergarten、恩物）
- **自然主義之父 / 教育界哥白尼** ➔ **盧梭**（《愛彌兒》、消極教育）
- **科學心理學之父** ➔ **馮德**（1879 萊比錫實驗室）
- **教育心理學之父** ➔ **桑代克**（試誤說、三大定律）
- **智力測驗之父** ➔ **比奈**（比西量表、心理年齡）

## 單元七：《學記》四大教學原則（預時孫摩）

- 📘 **預（豫）**：**「禁於未發之謂豫」** ➔ 預防不良行為於未然。
- ⏰ **時**：**「當其可之謂時」** ➔ 把握關鍵期及時施教。
- 🪜 **孫（遜）**：**「不陵節而施之謂孫」** ➔ 循序漸進，不跨越節度。
- 🤝 **摩**：**「相觀而善之謂摩」** ➔ 同儕互相觀摩切磋、相得益彰。
- 🌟 **啟發金句**：**「道而弗牽，強而弗抑，開而弗達」**。
