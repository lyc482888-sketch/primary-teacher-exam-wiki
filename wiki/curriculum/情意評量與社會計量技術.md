# 情意評量與社會計量技術

## 一句話定位
> 情意評量聚焦於學生的「態度、性格、情緒與班級人際互動」；透過軼事記錄、評定量表、莫里諾（Moreno）社會計量法與課程本位評量（CBA），協助國小導師精準掌握班級人際動態與特殊學童適應。

---

## 一、 情意評量技術與常見工具

| 評量技術 | 核心特徵與實施方式 | 優缺點與實務限制 | 教甄必考實施原則與題眼 |
| :--- | :--- | :--- | :--- |
| **軼事記錄法**<br>(Anecdotal Records) | 長期在自然真實情境下，記錄個別學童**突發、典型且具代表性的具體客觀行為事件**。 | 優點：記錄最真實鮮活之原始行為。<br>缺點：費時費力，易受觀察者主觀記憶遺忘干擾。 | **實施四大黃金原則**：<br>1. **即時記錄**（事後立即補記，防遺忘）。<br>2. **事實描述與主觀評釋嚴格分開**。<br>3. 每次聚焦於**單一具體事件**。<br>4. **須累積長期多筆觀察記錄後，始得做出綜合推論與輔導判斷**。 |
| **檢核表**<br>(Checklists) | 預先編製一系列目標行為項目清單，評量者僅需勾選行為**「出現（是）」或「未出現（否）」**。 | 優點：施測快速簡便、客觀性高。<br>缺點：**僅記錄有無，無法判定該行為的「品質優劣或頻率程度」**。 | 適合評量國小低年級常規禮貌、掃除工作步驟檢核。 |
| **評定量表**<br>(Rating Scales) | 在檢核表的基礎上，引進**程度量尺**（如李克特 5 點量尺），由評量者評定學生表現的等級或頻率。 | 優點：可量化心理特質與行為頻率。<br>缺點：**極易受到評定者主觀心理偏誤的干擾（五大誤差）**。 | 分為數字量尺、圖示量尺、敘述圖示量尺（以敘述圖示量尺客觀性最高）。 |
| **語意差別量表**<br>(Semantic Differential) | 由 **奧斯古德（Osgood）** 提出，運用一系列**語意相反的兩極形容詞**（如好-壞、強-弱、勤勞-懶惰），評估受試者對概念的情感態度。 | 包含三大心理向度：<br>1. **評價（Evaluation）**（好-壞）<br>2. **力量（Potency）**（強-弱）<br>3. **活動（Activity）**（主動-被動）。 | 適合測量國小學童對「數學課」、「學校」、「班導師」的深層心理感受與情意態度。 |

## 二、 評定量表五大主觀心理誤差（絕對必考）

評定量表在教甄中最常考評分者的心理偏誤，必須精準辨析：

| 誤差名稱 | 產生之心理機制與現象 | 國小教學現場實例 | 破題關鍵字 |
| :--- | :--- | :--- | :--- |
| **寬鬆偏誤**<br>(Leniency Error) | 評分者不忍給低分，傾向於給所有學生**高於真實水準的分數**。 | 導師打平時操行成績全部給 90 分以上。 | 偏向高分、皆大歡喜 |
| **嚴苛偏誤**<br>(Severity Error) | 評分者標準過於嚴厲苛刻，傾向於給所有學生**低於真實水準的分數**。 | 新任嚴師給全班期末生活常規成績普遍不及格。 | 偏向低分、過度嚴格 |
| **趨中偏誤**<br>(Central Tendency) | 評分者害怕承擔極端責任或對學生認識不清，評分**一律集中在中間等級**（如 3 分或 70 分）。 | 評分者為了安全起見，所有學生都勾選「尚可/普通」。 | 集中中間、避免極端 |
| **月暈效應／光環效應**<br>(Halo Effect) | 評分者受到學生**某項顯著特徵（如外貌、成績優異、乖巧聽話）的良好印象影響，進而對其所有其他無關特質全面給予高評價**。 | 老師因為小明數學成績頂尖，就主觀認為他品德高尚、人際關係也一定極佳。 | 一好百好、牽連評定、特定特質擴散 |
| **邏輯誤差**<br>(Logical Error) | 評分者在認知上**錯誤地將兩種本質上互不相干的特質綁定在一起**，認為具備特質 A 必然具備特質 B。 | 老師主觀認為「字跡工整端正的學生，智力一定特別聰明」；或「內向安靜的學生，創造力一定較差」。 | 特質間錯誤推論、主觀邏輯掛鉤 |

## 三、 莫里諾（Moreno）社會計量法（Sociometry）

社會計量法是測量班級團體內部**同儕人際吸引、排斥、社交地位與非正式組織結構**的強大技術：

### 1. 實施步驟與呈現工具
- **社會計量問卷**：設定具體情境（如「分組做專案你最想和誰同組？」、「下課玩遊戲你最不希望和誰一組？」），每位學童限填 2~3 位同儕。
- **社會計量矩陣（Sociometric Matrix）**：以雙向二維表格記錄全班相互選擇與被選擇的人數次數。
- **社會關係圖（Sociogram）**：
  - 以圖形視覺化展現人際網絡：**女性常以圓形表示、男性常以三角形表示**，實線單向箭頭表示單選，雙向箭頭表示互選。
- **猜是誰技術（Guess-Who Technique）**：
  - 提供正面或負面行為描述句（如「誰總是在同學難過時安慰別人？」、「誰常常在排隊時插隊起爭執？」），由學童自由提名符合的同學，診斷同儕真實評價。

### 2. 社會計量地位五大分類

| 社交地位類別 | 同儕正向提名（喜歡） | 同儕負向提名（不喜歡） | 現場心理特質與輔導策略 |
| :--- | :---: | :---: | :--- |
| **受歡迎學童（明星，Stars）** | **極高** | 極低 | 具同理心、合作技巧佳、情緒穩定，為班級非正式領袖。 |
| **被拒絕學童（Rejections）** | 極低 | **極高** | **最危險族群**！常具破壞性攻擊行為或過度退縮，易演變為霸凌對象或反社會偏差。須優先介入諮商。 |
| **被忽視學童（Isolates / Neglected）** | 極低 | 極低 | 在班上宛如「隱形人」，安靜害羞缺乏存在感，但並無敵意。需提供人際搭橋與合作學習機會。 |
| **爭議性學童（Controversial）** | **極高** | **極高** | 兩極化人物，有人極度崇拜、有人極度厭惡（如個性鮮明強勢的風雲人物）。 |
| **一般型學童（Average）** | 中等 | 中等 | 人數最多，人際關係平穩正常。 |

## 四、 課程本位評量（CBA, Curriculum-Based Assessment）

課程本位評量是以**學生目前實際正在學習的課堂教材內容**為基礎，進行直接、頻繁、短期的評量，以動態監控學生的學習成長：

| CBA 核心模式 | 評估指標與實施重點 | 國小資源班與特教應用 |
| :--- | :--- | :--- |
| **標準參照 CBA** | 依據教材進度擬定具體表現目標，檢核是否精熟達標。 | 檢查國語課每課生字聽寫通過率。 |
| **正確性基礎 CBA** | 重視學生在特定練習中的「答對比率」（正確率）。 | 數學加減法作業之正確答題百分比。 |
| **流暢性基礎 CBA**<br>(Curriculum-Based Measurement, CBM) | **以「單位時間內的正確反應次數」作為指標**，兼顧「速度」與「精確度」。 | **國小閱讀流暢度評量**（每分鐘朗讀正確字數 WCPM）、每分鐘完成心算題數。 |

## 五、 國小教甄歷屆必考題眼與口訣庫

1. **月暈效應 vs 邏輯誤差 秒殺辨析**：
   - **因為單一全貌好印象，導致所有特質皆給高分 ➔ 【月暈效應】**。
   - **自以為特質 A 與特質 B 有因果關係（字好看 = 頭腦好） ➔ 【邏輯誤差】**。
2. **社會計量法 ➔ 【莫里諾 Moreno】**：
   - 題幹出現「社會關係圖」、「猜是誰技術」、「班級小團體與邊緣人分析」➔ **必選莫里諾（Moreno）社會計量法**。
3. **被拒絕 vs 被忽視**：
   - 「被討厭次數最多」➔ **被拒絕學童**（最需輔導介入防範偏差）；「沒人選也沒人討厭」➔ **被忽視學童**。
