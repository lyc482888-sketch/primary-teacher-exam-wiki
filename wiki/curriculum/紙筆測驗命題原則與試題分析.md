# 紙筆測驗命題原則與試題分析

## 一句話定位
> 紙筆測驗以「雙向細目表」確保內容效度，並藉由命題技術與事後「試題分析（難度 P、鑑別度 D、誘答力）」檢驗題目品質，是國小定期評量與教甄考試最重要的技術核心。

---

## 一、 雙向細目表（Table of Specifications）

雙向細目表是編製成就測驗（如期中考、期末考）前必須擬定的測驗藍圖，旨在確保測驗具有高度的**內容效度**：

| 表格維度 | 核心配置內容 | 具體設計重點 |
| :--- | :--- | :--- |
| **橫軸（水平向度）** | **教學目標（Bloom 認知歷程向度）** | 涵蓋記憶、了解、應用、分析、評鑑、創造等不同認知層次。 |
| **縱軸（垂直向度）** | **教材內容（單元主題領域）** | 詳列本次評量所包含的各教學單元、章節或核心主題。 |
| **交叉細目單元** | **題數配置、題型與配分權重** | 依各單元的「重要性」與「教學時數比例」分配題數百分比。 |

> **教甄必考定律**：成就測驗為了建立「內容效度」，最核心的工具就是**雙向細目表**！

---

## 二、 各類紙筆題型之命題與評分原則

### 1. 是非題（True-False Items）
- 試題陳述應具**絕對的明確性**，非對即錯，避免模稜兩可。
- **避免使用雙重否定句**（如「沒有學生不討厭考試」），以免考驗語文理解而非學科知識。
- **避免含有暗示性的絕對字眼**（如「總是、絕對、完全、必然」通常是錯的；「有時、通常、可能」通常是對的）。
- **「對」與「錯」的題數比例應大致相當（約 1:1）**，且隨機錯開排列。

### 2. 選擇題（Multiple-Choice Items）
- **題幹（Stem）應具完整意義**：題幹本身應清楚呈現主要問題，即使不看選項也能理解提問核心。
- **避免「以上皆是」與「以上皆非」**：
  - 「以上皆是」易讓學生只要認出兩個選項正確即能猜中答案。
  - 「以上皆非」無法測出學生是否真正知道正確解答。
- **誘答選項（Distractors）必須具備「似真性（Plausibility）」**：能吸引缺乏精熟概念或抱持常見迷思的學生選答。
- 各選項文法結構一致、長度盡量相當（避免正確答案總是寫得最長最詳細）。

### 3. 配合題（Matching Items）
- **題目與選項性質必須「同質」**：同一大題內只能是同一範疇（如全為發明家與發明物、全為歷史人物與朝代）。
- **問題項與反應項數量「不相等」**：通常反應選項比問題項目多 2~3 個，避免學生以消去法輕易猜中最後一題。
- 整個配合題大題務必印在同一頁，避免翻頁干擾思考。

### 4. 申論題評分準則（提升評分信度五大原則）
1. **預先擬定明確的「評分規程（Rubrics）」與標準參考答案**。
2. **採「連續橫向閱卷」**：一次批改全體考生的同一題，批改完後再改下一題，避免前後標準漂移。
3. **採「匿名閱卷（隱藏姓名座號）」**：杜絕月暈效應（避免先入為主的學業印象）。
4. **兩位以上評分者獨立評分後取平均**：有效提高評分者信度。
5. 作答評分時將「書寫字跡工整度」與「學科實質論點」明確分開，避免邏輯誤差。

## 三、 試題分析（Item Analysis）指標與公式

依據凱利（Kelly, 1939）常模參照分組法，將全體受試者依測驗總分由高至低排序，取**前 27% 為「高分組（High Group, H）」**，取**後 27% 為「低分組（Low Group, L）」**：

### 1. 試題難度指數（Difficulty Index, P）
- **計算公式**：
  - 二分組公式：`P = (PH + PL) / 2`
  - 全體公式：`P = R / N`（R 為全體答對人數，N 為受試總人數）。
- **數值範圍**：`0.00 <= P <= 1.00`。
- **核心解讀（教甄必記反向邏輯）**：
  - **P 值愈大 ➔ 答對率愈高 ➔ 題目愈容易！**
  - **P 值愈小 ➔ 答對率愈低 ➔ 題目愈困難！**
  - **優良試題難度區間**：`0.40 <= P <= 0.70`。
  - **常模參照測驗平均難度以 `P = 0.50` 最理想**（此時分數變異數最大，鑑別力最高）。

### 2. 試題鑑別度指數（Discrimination Index, D）
- **計算公式**：
  - `D = PH - PL`（高分組答對率減去低分組答對率）。
- **數值範圍**：`-1.00 <= D <= +1.00`。
- **核心解讀**：
  - **D 值愈大 ➔ 鑑別力愈高**（高分組答對遠多於低分組）。
  - **Ebel 鑑別度品質標準評定表**：

| 鑑別度數值（D） | 試題品質評價 | 國小教學與命題實務處置 |
| :---: | :---: | :--- |
| **D >= 0.40** | **優良試題** | 品質極佳，直接收錄進入精緻試題庫。 |
| **0.30 <= D <= 0.39** | **良好試題** | 品質良好，通常無需大幅修改即可使用。 |
| **0.20 <= D <= 0.29** | **尚可試題** | 鑑別力邊緣，建議檢討題幹與誘答項後修訂。 |
| **D < 0.20** | **劣質試題** | 缺乏鑑別功能，必須進行大幅修改或直接淘汰。 |
| **D < 0（負值）** | **反向試題（致命缺失）** | **低分組答對率竟然高於高分組！** 必有嚴重瑕疵（如公佈解答錯誤、題目語意反諷具強烈誤導性），**應立即停用或刪除**。 |

## 四、 難度（P）與鑑別度（D）之數學關係

1. **試題難度直接制約鑑別度的理論上限**：
   - 當 `P = 0.50` 時，鑑別度的最大理論值可達 **+1.00**（高分組全員答對 PH=1.0，低分組全員答錯 PL=0）。
   - 當試題極端困難（`P = 0.10`）或極端容易（`P = 0.90`）時，鑑別度 D 的最高上限只有 **0.20**！
2. **總結律**：**試題難度適中（P 值接近 0.50），最容易產出高鑑別度的題目！**

## 五、 選擇題誘答力分析（Distractor Analysis）

誘答力分析旨在檢驗選擇題的「錯誤選項」是否發揮良性的迷惑功能。

### 優良誘答選項的三大判準
1. **吸引低分組人數應顯著多於高分組人數（`PL > PH`）**。
2. **每個誘答選項都應該至少有人選答**（無人選答的選項等同虛設，浪費題目空間）。
3. **高分組選答人數絕不能多於低分組（若 `PH > PL`，代表該誘答項具有高度反向誤導力，必須修訂）**。

### 教甄典型試題誘答表判讀實例

題目假設高分組與低分組各 50 人，正確答案為 (B)：

| 選項 | 高分組人數（H） | 低分組人數（L） | 狀態分析與評定處置 |
| :---: | :---: | :---: | :--- |
| **(A)** | 4 | 16 | **優良誘答項**：成功吸引低分組（16 > 4）。 |
| **(B) ★** | 40 | 12 | **正確答案**：`PH = 40/50 = 0.80`，`PL = 12/50 = 0.24`。<br>難度 `P = (0.80 + 0.24)/2 = 0.52`；鑑別度 `D = 0.80 - 0.24 = 0.56`（極優良）。 |
| **(C)** | 6 | 20 | **優良誘答項**：成功吸引低分組（20 > 6）。 |
| **(D)** | 0 | 2 | **無效誘答項**：幾乎無人選答，缺乏似真性，建議更換誘答情境。 |

## 六、 國小教甄歷屆必考題眼與口訣庫

1. **P 值與難易反比**：
   - 「P 值愈大愈簡單，P 值愈小題目難」。
2. **負鑑別度（D < 0）**：
   - 題幹出現「某題 D = -0.30，請問這題應該如何處置？」➔ **優先檢查是否答案公佈錯誤，或試題語意存在反向誤導，須刪除或修改**。
3. **成就測驗 ➔ 【雙向細目表】**：
   - 題幹強調「使試題兼顧教學目標與教材內容廣度」➔ **必選雙向細目表**。
