# 學校三級輔導體制與諮商歷程

## 一句話定位
> 依據《學生輔導法》與校園正向管教規範，統整初級發展性、次級介入性與三級處遇性之校園防護網，並剖析普羅卡斯卡個案改變六階段與團體諮商發展動態，為國小學校輔導實務出題熱區。

---

## 壹、 個案行為改變歷程：普羅卡斯卡（Prochaska）跨理論模式（TTM）

> 案主在面對偏差行為或成癮習慣時，其心理準備度歷經**連續六大改變階段**，輔導人員必須針對不同階段給予適配之介入：

```text
  醞釀前期 ➔ 醞釀期 ➔ 準備期 ➔ 行動期 ➔ 維持期 ➔ 終止期
  (無意圖)  (矛盾猶豫) (承諾計畫) (主動改變) (克服復發) (習慣固化)
```

1. **醞釀前期（Precontemplation）**：
   - *心理狀態*：個案未覺察改變的需求，否認問題存在，完全不想改變（「我抽菸或打電動關大家什麼事，我很好」）。
   - *輔導策略*：提供資訊、建立信任關係、引導覺察，**切忌強迫制定行動計畫**。
2. **醞釀期（Contemplation）**：
   - *心理狀態*：個案開始覺察問題嚴重性與自我責任，想要改變，但處於「想改又怕改、恐懼失敗」的**天平矛盾期（Ambivalence）**，裹足不前。
   - *輔導策略*：運用動機式晤談（Motivational Interviewing），分析改變的利弊得失，增強內在改變動機。
3. **準備期（Preparation）**：
   - *心理狀態*：個案已做出改變的承諾，開始收集資訊，並計畫在未來一個月內付諸行動。
   - *輔導策略*：協助設定合理可行的目標，擬定具體行動步驟。
4. **行動期（Action）**：
   - *心理狀態*：個案主動改變外在行為、生活方式或所處環境，投入大量心力。
   - *輔導策略*：給予正向增強與社會支持，教導因應技巧。
5. **維持期（Maintenance）**：
   - *心理狀態*：新行為已持續六個月以上，努力維持成果並防止問題行為復發。
   - *輔導策略*：預防復發訓練，協助處理生活壓力危機。
6. **終止期（Termination）**：
   - *心理狀態*：新行為已徹底內化為生活風格的一部分，完全不受誘因誘惑，具備百分之百的自我效能感。

## 貳、 團體諮商發展歷程與動力模式

### 一、 團體發展經典四階段
1. **初期階段（定向與探索）**：
   - 成員彼此陌生、焦慮不安；核心任務是**建立團體常模、安全感與信任感**。
2. **轉換階段（衝突與抗拒）**：
   - 成員表露真實自我與內在矛盾，面臨人際防衛、焦慮與權力爭奪；諮商師應**坦承接納並協助處理衝突，化挑戰為成長契機**。
3. **工作階段（凝聚與生產力）**：
   - 團體高度安全信任、開放坦率，焦點在探討核心議題並付諸具體行為改變。
4. **結束階段（統整與告別）**：
   - 處理離別情緒，統整團體學習經驗，擬定日常實踐承諾，做好面對外在世界的準備。

### 二、 塔克曼（Bruce Tuckman）團隊發展五階段對照

| 階段名稱 | 英文名稱 | 團隊互動特徵 | 輔導員或教師介入重點 |
| :--- | :--- | :--- | :--- |
| **形成期** | Forming | 成員互相試探摸索、依賴領導者、尋求接納。 | 破冰活動（如大風吹）、說明團體目標與建立規範。 |
| **風暴期** | Storming | 出現意見分歧、挑戰領導權威、次級小團體形成。 | 不偏袒、引導衝突公開對話、澄清團體價值。 |
| **規範期** | Norming | 建立團隊共識、彼此聆聽與尊重、凝聚力顯著提升。 | 強化團隊合作默契、促成相互支持氣氛。 |
| **執行期** | Performing | 成員高度自主、以任務達成與解決問題為導向。 | 扮演催化與資源提供者，協助成員深化學習。 |
| **解散期** | Adjourning | 任務完成準備解散，成員產生失落、焦慮或感傷。 | 處理分離焦慮、評估成效、落實後續追蹤。 |

## 參、 學校三級輔導體制架構（《學生輔導法》核心規範）

> 我國《學生輔導法》明定學校應建構「三級輔導工作機制」，界定全體教職員工的權責分工：

| 輔導金字塔層級 | 輔導定位 | 核心介入對象 | 主導與協同專業團隊 |
| :--- | :--- | :--- | :--- |
| **頂層：第三級輔導** | **處遇性輔導**（醫療與危機處遇） | 嚴重適應困難、心理疾患、重大偏差、自傷危機個案 | 學生輔導諮商中心、諮商/臨床心理師、社工師、精神醫療與社政司法網絡 |
| **中層：第二級輔導** | **介入性輔導**（早期介入與輔導） | 瀕臨偏差、學習適應困難、高關懷群、家庭變故學生 | 專任輔導教師、兼任輔導教師、認輔教師（個別諮商、專題小團體輔導） |
| **底層：第一級輔導** | **發展性輔導**（普及預防與奠基） | **全校全體學生**（促進身心全人發展、生命教育） | 全體教師、班級導師、各處室行政人員（班級經營、正向管教、友善校園） |

| 輔導層級 | 服務對象 | 主導與執行人員 | 核心任務與具體措施 |
| :--- | :--- | :--- | :--- |
| **初級預防**<br>(發展性輔導) | **全校全體學生** | 全體教師、班級導師、各處室行政人員 | 1. 普及性心理健康教育與生命教育。<br>2. 班級經營與正向管教措施。<br>3. 生涯探索與定向輔導活動。<br>4. 學生個別資料建立與觀察。 |
| **次級預防**<br>(介入性輔導) | **適應困難、瀕臨違規、高關懷群、受挫學生** | **專任輔導教師**、兼任輔導教師、認輔教師 | 1. 早期篩檢與鑑定評估。<br>2. 個別諮商與專題小團體輔導。<br>3. 教師與家長之輔導諮詢服務。<br>4. 推動校園「認輔制度」（認輔適應困難學生）。 |
| **三級預防**<br>(處遇性輔導) | **嚴重適應不良、重大偏差行為、精神病症、自我傷害危機個案** | 專輔教師結合**學生輔導諮商中心**之諮商心理師、臨床心理師、社工師及醫療團隊 | 1. 成立校園危機處理小組與個案管理。<br>2. 深度心理治療與精神醫療轉介。<br>3. 社政、警政、司法網絡跨專業合作。<br>4. 自殺防治後續追蹤與危機減壓。 |

## 肆、 推動校園正向管教工作方案與防制體罰機制

### 一、 教育部校園正向管教三級預防措施
1. **初級預防（發展性宣導）**：
   - 提升全體教師班級經營知能與情緒管理，鼓勵採用有效行為改變技術。
   - 制定透明民主班規，落實友善校園人權指標。
   - 避免因個人或少數人違規而株連處罰全體學生（嚴禁連坐法）。
2. **二級預防（介入與申訴）**：
   - 健全學生申訴制度，定期統計申訴案件。
   - 針對管教困難之教師提供專業研習與同儕團體支持。
   - 推動認輔制度，早期介入情緒困擾與行為偏差學童。
3. **三級預防（處遇與通報）**：
   - 發生教師違法處罰或體罰學生事件時，啟動危機處理標準作業流程。
   - 依「校園安全及災害事件通報作業要點」**依法限時通報**；情節重大者送交教師評審委員會（教評會）或考核會審議。
   - 引入專業心理諮商資源，對受害學生及行為教師進行個別諮商修復。

### 二、 葛拉塞（Glasser）《沒有失敗的學校》與留置室機制
- **反對體罰與標籤化**：體罰破壞師生共融關係，只會強化學生的失敗認同。
- **留置室（Time-out Room）運作原則**：
  - 專門安置在課堂上嚴重違規干擾教學的學生。
  - 由合格輔導專業人員主持，**非監禁或懲罰性場所**。
  - 提供冷靜、自我評估（WDEP）的沉思空間，直到學生願意簽署遵守班規的承諾計畫後，始得回歸原班級教學。
