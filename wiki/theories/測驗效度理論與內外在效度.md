# 測驗效度理論與內外在效度

## 一句話定位
> 效度（Validity）是指測驗「能真正測出其所欲測量特質或功能的程度」，是測驗最重要的特質；在實驗研究中則區分為確保因果關係的「內在效度」與確保可推論性的「外在效度」。

---

## 一、 效度概念與變異數分割

在測量理論中，測驗實得分數的總變異數（Sx²）可分割為三大成分：

| 變異數成分 | 符號表示 | 核心內涵與測量學意義 |
| :--- | :--- | :--- |
| **共同因素變異數** | **Sco²** | 測驗與外在效標共同分享的有效變異（**效度的來源**）。 |
| **特殊因素變異數** | **Ssp²** | 該測驗獨特具備但與效標無關的穩定變異（貢獻於信度，但不貢獻於該效度）。 |
| **隨機誤差變異數** | **Se²** | 不可預測的隨機測量誤差（同時戕害信度與效度）。 |
| **真實分數變異** | **St² = Sco² + Ssp²** | **信度等於共同變異加特殊變異佔總變異之比率**。 |
| **效度定義** | **rxy² = Sco² / Sx²** | **效度係數平方等於共同變異佔總變異之比率**。 |

---

## 二、 測驗效度的四大類型

美國心理學會（APA）將測驗效度劃分為四大核心面向：

| 效度種類 | 核心定義與提問 | 檢驗方法與代表工具 | 教甄高頻考點與題眼 |
| :--- | :--- | :--- | :--- |
| **內容效度**<br>(Content Validity) | 測驗試題的抽樣是否具**代表性**與**適切性**，能否完整涵蓋教學目標與課程領域。 | 1. 專家學者進行內容審查。<br>2. **雙向細目表（Table of Specifications）**。 | 成就測驗、段考期末考**最重視內容效度**。<br>※ **表面效度（Face Validity）**：外行受試者主觀覺得像不像測驗，非科學技術效度。<br>※ **現金效度（Cash Validity）**：坊間測驗書刊賣得好不好，純屬商業噱頭。 |
| **效標關聯效度**<br>(Criterion-Related) | 測驗分數與某種獨立外在標準（效標 Criterion）的相關係數高低。 | **相關分析法、迴歸分析、預期值表（Expectancy Table）**。 | 依效標取得時間分為兩大類：<br>1. **同時效度（Concurrent）**：效標同時取得（如新自編智商與舊魏氏智商相關）。<br>2. **預測效度（Predictive）**：效標在未來取得（如大學學測成績預測大一在校GPA）。性向測驗最重預測效度！<br>※ **效標污染（Criterion Contamination）**：評分者預先看過測驗成績，導致效標打分帶有主觀偏見，產生虛假高相關。 |
| **構念／建構效度**<br>(Construct Validity) | 測驗分數能被某種抽象心理學理論、概念或特質架構合理解釋的程度。 | 1. **聚斂效度（Convergent）**：不同方法測同一特質，相關要高。<br>2. **區辨效度（Discriminant）**：同種方法測不同特質，相關要低。<br>3. **多特質多方法矩陣（MTMM）**（Campbell & Fiske 提出）。<br>4. **因素分析（Factor Analysis）**。 | 人格測驗、創造力測驗、動機量表**最重構念效度**。<br>題目若出現「因素分析」、「探索潛在理論特質結構」➔ 必選構念效度。 |
| **後果效度**<br>(Consequential) | 測驗分數之使用與決策，對社會、學校及受試個人所造成的長遠正面或負面衝擊。 | 評估測驗推行後是否導致應試教學（Teaching to the test）、標籤化或教育不公。 | 由 **Messick（1989）** 提出，將測驗的「價值意涵」與「社會後果」納入廣義效度架構中。 |

## 三、 信度與效度之深層關係（必背對照）

| 比較維度 | 核心定律與教甄判斷則 | 正誤辨析與口訣 |
| :--- | :--- | :--- |
| **必要非充分條件** | **信度是效度的必要條件，但非充分條件**。 | 想要有效度，必須先有信度；但有了信度，不保證有效度。 |
| **互推邏輯** | 1. **有效度 ➔ 必定有信度**（真命題）。<br>2. **有信度 ➔ 不一定有效度**（可能測得很穩定，但測錯東西）。<br>3. **無信度 ➔ 絕對無效度**（真命題）。<br>4. **無效度 ➔ 仍可能有高信度**（如拿準確的磅秤測量數學能力）。 | 教甄是非題高頻陷阱：<br>「測驗信度高，效度一定高」➔ **錯誤！**<br>「測驗效度高，信度一定高」➔ **正確！** |
| **數學上限限制** | **效度係數的絕對值，絕不會超過信度係數的平方根**：<br>`rxy <= √(rxx)` | 實例計算：若測驗信度係數為 0.49，則該測驗之效度係數最高不超過 `√0.49 = 0.70`。 |

## 四、 實驗研究之內在效度與十二大威脅

**內在效度（Internal Validity）** 指研究中實驗處理（自變項）確實造成實驗結果（依變項）變化的確信程度，即**能否確立真正的因果關係**。

### 十二大內在效度威脅因素

| 威脅因素 | 具體內涵與現場實例 | 解決或控制策略 |
| :--- | :--- | :--- |
| **1. 歷史／同時事件（History）** | 在實驗進行期間，受試者遭遇研究以外的外部偶發事件（如實驗中途發生地震、疫情停課、校外補習）。 | 設立對等之控制組。 |
| **2. 成熟（Maturation）** | 受試者隨時間自然產生的生理或心理成長、疲勞、飢餓或厭倦。 | 縮短實驗期程，增設對照組。 |
| **3. 測驗效應（Testing）** | 前測經驗使受試者產生練習效應、熟悉題型或產生警覺，導致後測成績虛假提升。 | 採用所羅門四組設計（Solomon Four-Group Design）。 |
| **4. 工具變化（Instrumentation）** | 測量工具磨損、後測題目難度與前測不一致，或評分者標準隨時間變寬或變嚴。 | 校正儀器，評分者標準化培訓。 |
| **5. 統計迴歸（Statistical Regression）** | 挑選前測**極端高分或極端低分**的受試者進行實驗，其後測成績自然有「向團體平均數靠攏」的趨勢。 | 避免僅以單次極端分數作為唯一定組依據。 |
| **6. 選樣偏差（Selection）** | 實驗組與控制組在實驗開始前，成員在身心能力、動機等背景特質上即存在系統性不對等。 | **隨機分派（Random Assignment）**、配對組設計。 |
| **7. 樣本亡佚（Mortality）** | 實驗期間受試者因搬家、轉學、生病或失去興趣而中途退出，破壞組間均等性。 | 追蹤流失率，進行亡佚樣本特質分析。 |
| **8. 選樣與成熟交互作用** | 當實驗組與控制組選樣不均等時，兩組受試者之心理成長成熟速度不一致。 | 隨機分派入組。 |
| **9. 強亨利效應（John Henry Effect）** | **控制組**受試者知曉自己身處對照劣勢，**不甘示弱而激發超乎尋常的努力競爭**，拉近與實驗組的差距。 | 雙盲設計（Double-Blind）、隱蔽受試身分。 |
| **10. 處理擴散（Diffusion of Treatment）** | 實驗組與控制組彼此認識並私下交流學習，實驗組的教學教材或策略外溢至控制組。 | 物理空間隔離，避免組間交流。 |
| **11. 實驗者偏見（Experimenter Bias）** | 研究者本身的期望與偏見，自覺或不自覺地給予實驗組更多關照或暗示（畢馬龍效應）。 | 採雙盲設計，由第三方客觀人員施測。 |
| **12. 統計結論效度缺失** | 樣本數過小、統計檢定力（Power）不足，或違反統計假定導致錯誤接受虛無假設。 | 提高樣本容量，選用適切統計法。 |

## 五、 實驗研究之外在效度與威脅

**外在效度（External Validity）** 指研究結果能夠**推論至母群體或其他環境情境的程度**（代表性與可概化性）。

| 外在效度維度 | 核心考量 | 主要威脅因素 | 教甄必考經典現象 |
| :--- | :--- | :--- | :--- |
| **母體效度**<br>(Population Validity) | 研究結論能否推論至更廣大的受試母群體。 | 抽樣偏差、志願者偏誤（志願者動機通常高於一般人）。 | 僅以某菁英國小班級研究，無法推論至偏鄉弱勢學童。 |
| **生態效度**<br>(Ecological Validity) | 研究結論能否推論至其他學校、課堂或真實生活情境。 | **1. 霍桑效應（Hawthorne Effect）**：受試者知曉自己被特別挑選觀察，而表現出超常積極的行為。<br>**2. 新奇效應（Novelty Effect）**：受試者因對新教材教法感到新奇而短暫提升成績。<br>**3. 實驗情境過度人工化**：實驗室環境與真實吵雜課堂脫節。 | 題目若出現「工人被觀察產能提升」或「學生知道有教授入班觀課特別乖巧」➔ **必選霍桑效應**。 |

## 六、 國小教甄歷屆必考題眼與秒殺口訣

1. **霍桑效應 vs 強亨利效應 秒殺辨析**：
   - **受試者（通常為實驗組）知被觀察而更努力 ➔ 【霍桑效應】**。
   - **控制組（對照組）不甘示弱與之拚搏 ➔ 【強亨利效應】**（口訣：強亨利不服輸）。
2. **極端選樣 ➔ 【統計迴歸效應】**：
   - 題幹出現「挑選全校倒數 10% 進行補救教學，後測顯著提升，可能混淆何種因素？」➔ **秒選統計迴歸**。
3. **成就測驗 ➔ 【內容效度】＋【雙向細目表】**：
   - 題幹出現「國小定期評量為了確保命題涵蓋教材內容與教學目標」➔ **秒選雙向細目表、內容效度**。
