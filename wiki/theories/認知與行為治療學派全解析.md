# 認知與行為治療學派全解析

## 一句話定位
> 融合經典行為制約技術與認知重構策略，涵蓋傳統行為治療、艾里斯 REBT、貝克認知治療 CT 與麥欽鮑姆 CBM，為國小現場偏差行為矯正與情緒輔導的核心利器。

---

## 壹、 行為治療法（Behavior Therapy）

### 一、 核心哲理與工作特徵
1. **著重科學實證與客觀測量**：輔導目標必須操作化定義、具體且可衡量。
2. **強調此時此地（Here and Now）**：聚焦於當前引發與維持問題行為的環境制約因，而非深究童年創傷。
3. **輔導關係的定位**：良好的輔導關係是改變的「必要條件」，但非促成行為改變的「充分條件」；輔導員扮演**教師、示範者與行為教練**。

### 二、 核心行為改變技術分類
- **正增強（Positive Reinforcement）**：適當行為出現後給予喜愛刺激，增加該行為頻率。
- **負增強（Negative Reinforcement）**：適當行為出現後移除嫌惡刺激，以維持或增強該行為。
- **懲罰（Punishment）**：不良行為出現時施加嫌惡刺激或剝奪喜愛刺激，以削弱不良行為。
- **消弱（Extinction）**：當不良行為出現時撤除原先維持該行為的增強物（如忽視尋求注意的哭鬧），使其逐漸消失。
- **相互制約原理（Reciprocal Inhibition，Wolpe）**：神經系統無法同時處於兩種完全對立的生理狀態（如放鬆狀態與焦慮狀態互不相容）；當以放鬆抑制焦慮時，焦慮制約即被瓦解。

### 三、 國小教甄高頻特殊技術庫
1. **系統減敏感法（Systematic Desensitization，Wolpe）**：
   - 專門用於治療恐懼症、考試焦慮。
   - **標準三步驟**：
     - *第一步：訂定焦慮階層表*：引導案主列出 10~15 個引發焦慮情境，由最微弱（0分）排列至最極端恐懼（100分）。
     - *第二步：肌肉鬆弛訓練*：教導漸進式肌肉收縮與放鬆技巧，達至身心完全放鬆。
     - *第三步：循序減敏感*：案主處於深層放鬆下，從焦慮階層最低者開始想像；一旦感知微弱焦慮即示意暫停並重新放鬆，直至最高階層情境不再引起焦慮。
2. **代幣制（Token Economy）**：
   - 以具有象徵價值的代幣（如貼紙、籌碼）作為次級增強物，累積後可兌換案主喜愛的後備增強物（如自由活動時間、獎品）；代幣給予與扣除必須規則透明。
3. **內爆法（Implosive Therapy） vs 洪水法（Flooding）**：
   - 讓案主在想像中（內爆法）或現實情境中（洪水法）直接暴露於最強烈的焦慮刺激中，且不允許逃避，在無負面後果發生後使焦慮自然消退。
4. **自主訓練法（Assertive Training，肯定訓練）**：
   - 社交技能訓練，透過角色扮演、教導與示範，協助被動退縮或過度攻擊的學生勇於以合宜堅定方式表達自我權利與真實感受。
5. **自我管理方案（Self-Management Program）**：
   - 包含五大歷程：確立目標 ➔ 操作化定義目標 ➔ 自我監控（記錄頻率） ➔ 擬定自我增強契約 ➔ 自我評價與調整。

## 貳、 艾里斯（Albert Ellis）理性情緒行為治療（REBT）

### 一、 人性觀與核心論點
- 人天生同時具備理性思考與非理性思考的傾向。
- **情緒困擾並非由外在事件直接引發，而是源自個體對該事件所持有的「非理性信念（Irrational Beliefs）」**。
- 非理性信念三大特徵：**絕對化的要求（Must, Should, Ought）**、**過度誇大災難化（Awfulizing）**、**低挫折容忍力（I-can't-stand-it-itis）**。

### 二、 A-B-C-D-E-F 人格與治療模型
- **A（Activating Event）**：誘發事件（如：數學考試不及格）。
- **B（Belief System）**：案主的信念體系（理性信念 rB vs 非理性信念 iB：「我數學考差了，我就是個徹頭徹尾的廢物，大家都討厭我」）。
- **C（Consequence）**：認知、情緒與行為結果（如：極度憂鬱、逃學退縮）。
- **D（Disputing）**：諮商師進行**積極駁斥與辯論**（運用產婆辯論術、蘇格拉底詰問質疑非理性信念的邏輯性與實證證據）。
- **E（Effective Philosophy）**：建立務實、寬容與彈性的**新理性哲學**。
- **F（New Feeling）**：產生合宜的新情緒與積極行為。

### 三、 REBT 特色技術
- **駁斥技術（Disputing）**：直接挑戰「憑什麼你非得第一名不可？如果不完美世界就會毀滅嗎？」。
- **對抗羞辱練習（Shame-attacking Exercises）**：要求案主在公眾場合做出稍微古怪但無害的行為（如在地鐵上大聲報站），體會「即便別人側目，天也不會塌下來」，擺脫病態羞恥感。

## 參、 貝克（Aaron Beck）認知治療法（Cognitive Therapy, CT）

### 一、 核心架構與概念
- 認為心理困擾導源於**負向自動化思考（Automatic Thoughts）**與潛藏在深層的**功能失調基模（Cognitive Schemas）**。
- 貝克提出憂鬱症的**認知三徵兆（Cognitive Triad）**：對**自我**抱持負向看法、對**當前經驗**進行悲觀詮釋、對**未來**抱持絕望預期。

### 二、 八大高頻認知扭曲（國小教甄選擇題必考）

| 認知扭曲類型 | 英文術語 | 核心定義與思維陷阱 | 國小學生現場實例 |
| :--- | :--- | :--- | :--- |
| **獨斷推論** | Arbitrary Inference | 沒有充足而相關的客觀證據，便驟下負面結論。 | 老師今天沒對我笑，一定是我做錯事討厭我了。 |
| **選擇性推論** | Selective Abstraction | 僅抓取全貌中的單一微小負面細節，忽視其餘正向事實。 | 考卷拿了 95 分，卻整天為寫錯的 5 分痛哭自責。 |
| **過度類化** | Overgeneralization | 將單一偶發事件之結論，不當推論至所有不相關情境。 | 這次田徑賽沒跑好，我這輩子什麼事情都做不好。 |
| **擴大與誇張** | Magnification / Minimization | 過度誇大自己的缺點與失誤，同時嚴重縮小自己的優勢。 | 運動會得名只是運氣好，我本質上還是一無是處。 |
| **個人化** | Personalization | 毫無根據地將外在不幸事件全歸咎於自己一人。 | 爸媽今天吵架離婚，都是因為我不夠乖造成的。 |
| **極端化二分法思考** | Polarized Thinking (Either/Or) | 非黑即白、全有全無，不容許中間灰色地帶。 | 我如果不能考到全班第一名，我就是個徹底的失敗者。 |
| **災難化思考** | Catastrophizing | 將原本微小的挫折想像為毀滅性的終極災難。 | 如果明天上台報告忘詞，我的人生就全毀了。 |
| **錯誤標籤化** | Mislabeling | 根據單一行為過失，直接給自己或他人貼上死性不改的標籤。 | 我這次數學計算粗心，我根本就是個天生白痴。 |

### 三、 貝克的合作經驗主義（Collaborative Empiricism）
- 諮商師與案主組成**「科學探究同盟」**，不採取 REBT 的直接面質辯論，而是透過**引導式發現（Guided Discovery）**與蘇格拉底對話，像科學家做實驗般檢視信念的真偽。
- **想法真實性驗證技術（雙欄檢驗法）**：製作左右雙欄表格，左欄列出「支持該信念的客觀證據」，右欄列出「反對該信念的客觀事實」，由案主自主看清邏輯漏洞。

## 肆、 麥欽鮑姆（Donald Meichenbaum）認知行為矯正（CBM）

### 一、 核心理論：內部語言與自我指導訓練（SIT）
- 行為改變的先決條件是**改變當事人的內部對話（Self-Verbalizations）**；言談如何對待自己，行為就如何展現。
- **自我指導訓練流程**：
  1. 認知示範（成人大聲自言自語示範解題步驟）
  2. 外顯指導（孩童在成人大聲指引下操作）
  3. 外顯自我指導（孩童自己大聲說出步驟並操作）
  4. 隱蔽外顯自我指導（孩童低聲咕噥自語操作）
  5. 隱蔽自我指導（孩童在心裡默念自我對話指引行動）。

### 二、 行為改變的三大階段
1. **第一階段：自我觀察**：學習覺察自己的行為、情緒與負向內在對話。
2. **第二階段：開始新的內部對話**：重構認知，在關鍵時刻介入新的自我陳述（「慢慢來，深呼吸，我可以一步步完成」）。
3. **第三階段：學習新技巧與演練**：在真實生活情境中實踐因應技巧，建立穩定正向循環。

### 三、 壓力免疫訓練（Stress Inoculation Training, SIT）三大階段
- 類比於生理注射疫苗，先承受小幅度壓力挑戰，建立心理免疫力：
  1. **概念化階段（Conceptual Stage）**：了解壓力的本質與身心交互歷程。
  2. **技能獲得與演練階段（Skills Acquisition Stage）**：學習放鬆、認知因應語句與問題解決策略。
  3. **應用與持續階段（Application Phase）**：在角色扮演或真實壓力情境中實踐與維持。

## 伍、 認知三巨頭橫向對照大矩陣

| 比較維度 | 艾里斯（Ellis）REBT | 貝克（Beck）CT | 麥欽鮑姆（Meichenbaum）CBM |
| :--- | :--- | :--- | :--- |
| **不良認知名稱** | 非理性信念（iB） | 認知扭曲／功能失調基模 | 負向內在對話（自我語言） |
| **識別不良認知** | 諮商師直接指明與指出 | 採蘇格拉底提問、引導式發現 | 從實際行為不良影響評定 |
| **駁斥處理方式** | 直接辯論、哲學駁斥、面質 | 合作經驗主義、尋找客觀反證 | 不強調直接駁斥，強調以新語言覆蓋 |
| **良好認知建立** | 建立新理性生活哲學 | 認知重構、行為實驗檢驗 | 自我指導訓練、壓力免疫訓練（SIT） |
| **治療者角色** | 指導性教師、辯論家 | 合作的研究夥伴、導引者 | 行為示範者、內在教練 |
| **治療核心目標** | 徹底改變整個非理性哲學觀 | 矯正特定認知扭曲與憂鬱基模 | 改變特定內在語言以調整外在行為 |
