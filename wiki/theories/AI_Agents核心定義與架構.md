# AI Agents 核心定義與架構

## 一句話定位
> AI Agent（人工智慧代理人）是以大型語言模型（LLM）為認知大腦，具備自主規劃、感知環境、記憶存取與工具調用能力，能獨立完成複雜目標任務的智慧實體。

---

## 一、 傳統 Chatbot vs AI Agent 根本差異

| 比較維度 | 傳統對話機器人（Chatbot） | 人工智慧代理人（AI Agent） |
| :--- | :--- | :--- |
| **互動模式** | **被動單向回應**：使用者問一句，模型答一句。 | **主動自主達成目標**：給定單一目標，自動拆解並持續推進。 |
| **運作範疇** | 侷限於自身訓練參數內的文字生成。 | **能感知外部世界並操作工具**（上網、改檔、執行軟體）。 |
| **執行步驟** | 單次回合（Single-turn）直接輸出結果。 | **多步自主循環（Multi-step Loop）**：思考 ➔ 行動 ➔ 檢查 ➔ 修正。 |
| **錯誤自省** | 若答案錯誤，需使用者手動提醒糾正。 | **具備自我反思機制（Self-Correction）**：遇到報錯自動換方法重試。 |
| **代表情境** | 「請幫我寫一封請假信草稿。」 | 「請幫我分析這份 100 頁報告，整理成網頁並自動發布到 GitHub。」 |

## 二、 AI Agent 四大核心組件（Weng 經典架構）

當代 AI Agent 系統普遍建立在四大核心支柱之上：

| 組件名稱 | 比喻角色 | 核心職責與技術實現 |
| :--- | :---: | :--- |
| **1. 認知大腦（Brain / Planning）** | **總裁／指揮官** | 由大型語言模型（LLM）擔任，負責意圖解析、目標分解、優先順序排程與自我決策反思。 |
| **2. 感官知覺（Perception）** | **眼睛／耳朵** | 接收使用者輸入、觀察作業系統環境、解析外部 API 回應與終端機執行日誌。 |
| **3. 記憶系統（Memory）** | **記事本與資料庫** | 區分為「短期工作記憶（Context Window）」與「長期持久記憶（向量檢索 RAG / 結構化 Wiki）」。 |
| **4. 執行工具（Action / Tools）** | **雙手與外骨骼** | 檔案讀寫、終端機命令執行、網路搜尋、資料庫查詢、程式碼編譯器等外部能力擴充。 |

## 三、 Agentic Workflow（代理人工作流）的演進

從早期純靠提示詞工程（Prompt Engineering），演進到代理人工作流：

1. **零樣本生成（Zero-Shot）**：直接期望模型一次猜對全部答案（最容易產生幻覺）。
2. **思維鏈（Chain-of-Thought, CoT）**：要求模型「一步一步思考」，提升邏輯推理正確率。
3. **自主代理循環（Agentic Loop）**：模型在思考過程中，主動調用外部工具驗證中間事實，並依據結果動態導航至最終解答。
