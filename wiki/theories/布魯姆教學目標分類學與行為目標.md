# 布魯姆教學目標分類學與行為目標

## 一句話定位
> 布魯姆（Bloom）將教學目標分為「認知、情意、動作技能」三大領域；2001 年安德森（Anderson）將認知領域修訂為「知識向度 × 認知歷程向度」二維矩陣，是國小素養導向命題與雙向細目表的最高指導準則。

---

## 一、 認知領域教學目標演進（1956 舊版 vs 2001 修訂版）

| 比較維度 | 1956 年 Bloom 原創版 | 2001 年 Anderson & Krathwohl 修訂版 |
| :--- | :--- | :--- |
| **結構架構** | 單一維度（名詞階層體系） | **二維矩陣**（知識向度 × 認知歷程向度） |
| **詞性表達** | 以「名詞」表示認知狀態 | 改以「**動詞**」表示學生的心理行動歷程 |
| **最高層次** | **評鑑（Evaluation）** 為第6層最高峰 | **創造（Create）** 躍居第6層最高峰，評鑑退為第5層 |
| **層次階梯** | 知識 ➔ 理解 ➔ 應用 ➔ 分析 ➔ 綜合 ➔ 評鑑 | **記憶 ➔ 了解 ➔ 應用 ➔ 分析 ➔ 評鑑 ➔ 創造** |

---

## 二、 2001 年修訂版認知領域二維架構（核心考點）

### 1. 知識向度（Knowledge Dimension，名詞）

| 知識層次 | 核心內涵與教甄定義 | 具體教學實例 |
| :--- | :--- | :--- |
| **事實知識**<br>(Factual) | 學生必須知曉的基本個別元素、術語、標記與特定細節。 | 認識各縣市名稱、記住九九乘法表、知道氧氣符號是 O₂。 |
| **概念知識**<br>(Conceptual) | 各基本元素之間的關係與組織結構，包含分類、原理、通則與理論模型。 | 理解食物鏈與生態平衡的原理、掌握民主憲政體制運作架構。 |
| **程序知識**<br>(Procedural) | 做某件事的方法、步驟、技能、演算法與決定使用時機的規準（How to do）。 | 直式除法計算步驟、自然科顯微鏡操作標準流程、水彩畫筆法。 |
| **後設認知知識**<br>(Metacognitive) | 對於「認知本身的認知」，包含策略性知識、認知作業條件與自我反省監控。 | 了解自己適合用「心智圖」記憶、知道自己在疲勞時容易讀錯題。 |

### 2. 認知歷程向度（Cognitive Process Dimension，動詞）

| 層次（由低至高） | 核心動詞概念 | 具體認知子歷程與題眼動詞 |
| :--- | :--- | :--- |
| **1. 記憶（Remember）** | 從長效記憶中提取相關知識。 | **識別**（指認）、**回憶**（背誦默寫）。 |
| **2. 了解（Understand）** | 從教學訊息（口語、文字、圖形）建構意義。 | **詮釋**（換言之）、**舉例**（舉出實例）、**分類**（歸類）、**總結**（摘要大意）、**推論**（推測後續）、**比較**（辨析異同）、**解釋**（說明因果）。 |
| **3. 應用（Apply）** | 在給定的情境中執行或使用某項程序。 | **執行**（例行程序操作）、**實作**（在新情境中套用公式解題）。 |
| **4. 分析（Analyze）** | 將材料分解為各組成部分，釐清部分與整體之關聯。 | **區辨**（區分相關與無關資訊）、**組織**（建立結構圖）、**歸因**（找出作者隱含立場與偏見）。 |
| **5. 評鑑（Evaluate）** | 根據規準（Criteria）與標準做出客觀判斷與批判。 | **檢查**（檢視內在邏輯矛盾）、**評論／批判**（依外部規準評定作品優缺點）。 |
| **6. 創造（Create）** | 將要素重新整合組合成一個全新的、融通的整體或原創作品。 | **產生**（腦力激盪新點子）、**規劃**（擬定研究實驗計畫）、**製作**（創作新詩、發明模型）。 |

## 三、 情意領域教學目標（Krathwohl 五層次階梯）

情意領域強調學生態度、價值觀、興趣與品格的內化歷程，層次由外在被動走向內在融合：

| 階梯層次 | 核心內涵與心理歷程 | 國小教育現場具體表現 | 教甄秒殺關鍵字 |
| :---: | :--- | :--- | :--- |
| **1. 接受／注意**<br>(Receiving) | 意識到某種現象的存在，願意被動或主動給予關注。 | 學生願意安靜聆聽古典音樂、注意老師講課。 | 願意聆聽、注意、察覺 |
| **2. 反應**<br>(Responding) | 不僅注意，更積極主動參與並獲得情緒上的滿足。 | 主動舉手發言、樂於參與環保淨灘活動。 | 主動參與、樂於遵守、服從 |
| **3. 價值判斷／評價**<br>(Valuing) | 將特定事物、現象或行為賦予價值信念，產生認同與偏好。 | 表達對多元文化的尊重、主動支持資源回收並說服他人。 | 認同、支持、尊重、珍視 |
| **4. 價值的組織**<br>(Organization) | 將多種衝突的價值觀進行辨析、調和，建構個人的價值體系。 | 在「個人利益」與「公共利益」衝突時建立取捨準則。 | 調和、整合、建立體系 |
| **5. 價值的性格化**<br>(Characterization) | 價值觀完全內化為個人深層人格特質，言行一致且持之以恆。 | 終身奉行誠信原則、一生致力於人權與弱勢關懷。 | 品格形成、奉行一生、人格化 |

## 四、 動作技能領域教學目標（Simpson 七層次）

辛普森（Simpson）將動作技能學習劃分為從知覺到創新的七個遞進階段：

1. **知覺（Perception）**：透過感官察覺動作刺激與線索。
2. **心向（Set）**：身心做好執行該動作的準備狀態（心理、生理、情緒準備）。
3. **模仿引導（Guided Response）**：在教師示範與指導下進行初步模仿嘗試。
4. **機械練習（Mechanism）**：動作已達熟練程度，能自主連貫完成動作（如不用看鍵盤盲打）。
5. **複雜外顯反應（Complex Overt Response）**：能高度流暢、精確且迅速地完成高難度動作技能（如體操選手高難度空翻）。
6. **技能調適（Adaptation）**：動作技能高度純熟，能依據突發新情境靈活改變動作（如籃球員依防守變換運球招式）。
7. **創作（Origination）**：基於高超技能，自創全新動作風格或舞步。

## 五、 行為目標 vs 表意目標

在課程目標撰寫上，行為主義與人文批判學派存在鮮明對比：

| 目標類型 | 倡導學者 | 核心理念與結構 | 國小教學實例與評量特點 |
| :--- | :--- | :--- | :--- |
| **行為目標**<br>(Behavioral Objectives) | **梅傑（Mager）** | 強調目標必須具體化為**可觀察、可測量**的外顯行為。<br>**梅傑 ABCD 原則**：<br>1. **A（Audience）**：對象（國小三年級學童）。<br>2. **B（Behavior）**：行為動詞（能寫出、能計算）。<br>3. **C（Condition）**：情境條件（在不用計算機情況下）。<br>4. **D（Degree）**：評量規準（在十分鐘內答對8題以上）。 | 適合精熟學習、客觀紙筆測驗與基礎學科知識。缺點：易窄化學習，忽略高層次與無法量化之情意目標。 |
| **表意目標**<br>(Expressive Objectives) | **艾斯納（Eisner）** | 反對將教育窄化為預設的行為指標。強調學生在豐富教育情境中**開放、獨特、自發的體驗與感受**。不預設標準答案！ | 參觀美術館後寫下個人獨特感受、閱讀繪本後表達個人生活共鳴。適合藝術人文、閱讀省思與檔案評量。 |

## 六、 國小教甄高頻考點與陷阱提示

1. **「創造」取代「評鑑」成為最高層次**：
   - 舊版 Bloom 1956 最高為「評鑑」；新版 2001 Anderson 最高為「創造」。考題若問修訂版最高階認知歷程 ➔ **必選創造**。
2. **了解（Understand）的子歷程陷阱**：
   - 「舉出實例」屬於了解層次，常被誤選為應用；「用自己的話解釋」屬於了解層次的詮釋。
   - 「應用」強調必須是**執行特定程序解決問題**。
3. **情意領域第三層「價值判斷」**：
   - 題幹出現「某生主動認同並公開倡導性別平權」➔ 屬於情意領域的**價值評定（Valuing）**。
