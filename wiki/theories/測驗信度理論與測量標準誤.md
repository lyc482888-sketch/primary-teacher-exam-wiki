# 測驗信度理論與測量標準誤

## 一句話定位
> 信度是測驗結果的「一致性、穩定性與可靠性」，為效度的必要條件，核心指標為古典測驗理論的真分數模型與測量標準誤（SEM）。

---

## 一、 古典測驗理論（CTT）真分數模型

古典測驗理論假定：受試者在測驗上的實得分數（Observed Score, X），由「真實分數」（True Score, T）與「測量誤差」（Error Score, E）兩部分所組成：

| 模型要素 | 數學表示 | 核心內涵與教甄考點 |
| :--- | :--- | :--- |
| **實得分數** | **X** | 個人在測驗中實際取得之原始分數。 |
| **真正分數** | **T** | 受試者在無限次重複施測下所得分數的平均值（固定不變的潛在特質值）。 |
| **誤差分數** | **E** | 隨機產生的非系統性測量偏差，其期望平均值為 0（即 E 之總和趨近於 0）。 |
| **加法公式** | **X = T + E** | 實得分數為真分數與誤差分數的線性相加。 |
| **變異數分割** | **Sx² = St² + Se²** | 實得分數的總變異數（Sx²）等於真分數變異（St²）加上誤差變異（Se²）。 |
| **信度定義** | **rxx = St² / Sx²** | **信度即為「真正分數變異佔總變異數的百分比」**，範圍介於 0.00 至 1.00 之間（無負值）。 |

### 測量誤差類型比較

| 誤差類型 | 產生原因與實例 | 對信度與效度的影響 | 教甄判題關鍵 |
| :--- | :--- | :--- | :--- |
| **系統誤差（偏誤）** | 測驗題目難度一致偏難、測驗時間整體縮短、評分者固定寬鬆或嚴苛。 | **不影響信度**（因為一致偏高或偏低，排序不變），但**直接戕害效度**。 | 題目若出現「量尺固定多給 5 分」➔ 信度不變，效度降低。 |
| **隨機誤差（非系統誤差）** | 學生當日身體不適、考場突然噪音干擾、疲勞、猜測作答、閱卷疏忽。 | **直接降低信度**，進而連帶損及效度。 | 任何「不可預測、無規律」干擾 ➔ 隨機誤差 ➔ 戕害信度。 |

## 二、 常模參照測驗之信度估計方法

| 信度類型 | 施測方式 | 評估之一致性向度 | 誤差來源（考題必考） | 限制與注意事項 |
| :--- | :--- | :--- | :--- | :--- |
| **重測信度**<br>(Test-Retest) | 同一份測驗對同一群學生，**間隔一段時間施測兩次**。 | **跨時間之穩定性**（Stability）。 | **時間抽樣誤差**（受試者身心狀態、練習效應、記憶干擾）。 | 間隔時間太短易有記憶練習效應；間隔太長受身心成熟與學習干擾。 |
| **複本信度**<br>(Alternate-Form) | 同一群學生施測**內容、難度、長度等值**的兩份測驗（可同時或間隔施測）。 | 同時施測：**等值性**；<br>間隔施測：**穩定與等值性**。 | 同時施測：**內容抽樣誤差**；<br>間隔施測：**內容抽樣 + 時間抽樣**。 | 最嚴謹之信度估計法，但編製真正等值之複本極為困難且成本昂貴。 |
| **折半信度**<br>(Split-Half) | 單次施測一份測驗，將試題隨機或奇偶數拆為**題數相等的兩半**計算相關。 | **試題取樣之一致性**（內部一致性）。 | **內容抽樣誤差**。 | 僅代表半份測驗信度，**必須使用斯布公式（Spearman-Brown）校正回全測驗信度**。 |
| **庫李信度**<br>(KR-20 / KR-21) | 單次施測，計算所有試題間的同質關聯性。 | **試題同質性與內部一致性**。 | **內容抽樣與內容異質性**。 | **僅適用於「二元計分（對/錯、1分/0分）」之客觀選擇題**；KR-20 精確，KR-21 假設各題難度相等。 |
| **克隆巴赫 α 係數**<br>(Cronbach's α) | 單次施測，計算試題共變數與總變異比。 | **多元評分題目的內部一致性**。 | **內容抽樣與內容異質性**。 | **廣泛適用於「非二元計分（多元給分）」**，如李克特 5 點量表、問卷、申論題評分。 |
| **評分者信度**<br>(Scorer Reliability) | 多位評分者對同一批學生之主觀作答（申論、作文、實作）獨立評分。 | **評分者之間的主觀判定一致性**。 | **評分者個人偏見、疲勞與標準寬嚴誤差**。 | **2位評分者採 Spearman 等級相關或積差相關**；**3位以上評分者採 Kendall 和諧係數（W）**。 |

## 三、 標準參照測驗之信度估計

標準參照測驗（CRT）重視個人是否精熟門檻（及格/不及格），傳統相關係數不適用，改採**領域參照一致性指標**：

| 信度指標 | 計算意義與特色 | 公式概念 |
| :--- | :--- | :--- |
| **百分比一致性（PA）** | 受試者在前後兩次施測中，被歸類為同一等級（同為及格或同為不及格）之人數佔全體比例。 | `PA = (A + D) / N`（A 為兩次皆精熟，D 為兩次皆未精熟）。缺點：未扣除機遇猜測成分。 |
| **Cohen's Kappa 係數（κ）** | **扣除隨機機遇（Chance）一致性之後**的真實分類穩定係數，為國小教甄高頻考點。 | `κ = (Po - Pe) / (1 - Pe)`（Po 為實得一致性比例，Pe 為機遇一致性比例）。 |
| **李氏係數（Livingston k²）** | 結合古典測驗理論與合格分數門檻，考驗受試者與合格標準之距離穩定性。 | 將及格門檻納入變異數估算，門檻離平均數愈遠，信度係數愈高。 |

## 四、 測量標準誤（SEM）與信賴區間

測量標準誤（Standard Error of Measurement, SEM）是評估個人測驗分數精確度的指標，反映實得分數圍繞真正分數的變異標準差。

### 1. 計算公式與變數關係
- **標準公式**：`SEM = Sx × √(1 - rxx)`
  - `Sx`：測驗實得分數之標準差。
  - `rxx`：測驗之信度係數。
- **指標定律**：
  - 當信度 `rxx = 1.00` 時，`SEM = 0`（完全無測量誤差）。
  - 當信度 `rxx = 0.00` 時，`SEM = Sx`（測量分數純屬隨機誤差）。
  - **信度愈高 ➔ 測量標準誤愈小 ➔ 分數估計愈精確**。
  - **測驗標準差愈大 ➔ 測量標準誤愈大**。

### 2. 真實分數信賴區間（Confidence Intervals）

在常態分配假設下，受試者的真正分數（T）有固定機率落在實得分數（X）的信賴區間內：

| 信賴水準 | 區間範圍公式 | 教甄速解技巧 |
| :--- | :--- | :--- |
| **68% 信賴區間** | **[ X - 1(SEM) , X + 1(SEM) ]** | 真正分數有 68% 機率落於實得分數加減 1 個 SEM 內。 |
| **95% 信賴區間** | **[ X - 1.96(SEM) , X + 1.96(SEM) ]** | 教甄計算題若無特別指定 1.96，常概算為 **X ± 2(SEM)**。 |
| **99% 信賴區間** | **[ X - 2.58(SEM) , X + 2.58(SEM) ]** | 概算為 **X ± 2.6(SEM)** 或 **X ± 3(SEM)**。 |

## 五、 影響測驗信度的關鍵因素

1. **測驗長度（題數）**：
   - 題數愈多，試題對領域取樣愈具代表性，**信度愈高**。
   - 題數增減之信度校正採**斯布增長公式（Spearman-Brown Prophecy Formula）**：
     `rkk = (k × rxx) / [1 + (k - 1) × rxx]`（k 為題數增減倍數）。
2. **受試者團體之異質性**：
   - 團體成員能力**全距愈大、愈異質 ➔ 分數變異數 Sx² 愈大 ➔ 信度係數愈高**。
   - 團體愈同質（如資優班或特教班），分數集中 ➔ 信度係數降低。
3. **試題難度**：
   - 試題平均難度（P 值）接近 **0.50（中等難度）** 時，分數變異數最大，**測驗信度最高**。
   - 試題過難（正偏態）或過易（負偏態）皆使分數集中，信度降低。
4. **評分客觀性**：
   - 客觀題（選擇、是非）評分者信度最高（接近 1.0）；主觀申論題若未建立評分標準規準（Rubrics），信度大幅滑落。
5. **施測情境標準化**：
   - 施測說明、計時控制、考場安靜程度越標準化，隨機誤差越少，信度越高。

## 六、 國小教甄歷屆考點與陷阱題眼

1. **「信度是效度的必要條件，而非充分條件」**：
   - 有效度必定有信度（正確）；有信度不一定有效度（正確）。
   - 信度低，效度一定低（正確）；效度低，信度不一定低（正確，可能測得很精準但測錯東西）。
2. **「信度最大值限制效度」**：
   - **效度係數的上限等於信度係數的平方根**（`rxy <= √(rxx)`）。
   - 題目範例：若某測驗信度為 0.64，則該測驗之效度係數最大不可能超過 `√0.64 = 0.80`。
3. **折半信度未校正陷阱**：
   - 題目問：「兩半題目相關係數為 0.60，則整份測驗之信度為？」
   - 解題切記套用斯布公式：`2 × 0.60 / (1 + 0.60) = 1.20 / 1.60 = 0.75`，切勿直接回答 0.60！
