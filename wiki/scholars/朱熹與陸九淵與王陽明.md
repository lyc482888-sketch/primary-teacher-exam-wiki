# 宋明理學與心學巨擘：朱熹、陸九淵與王陽明

## 一句話定位
> 宋明新儒學的兩大哲學陣營——「程朱理學」與「陸王心學」，在知識論、本體論與知行觀上展開千年最具深度的思想辯論。

---

## 核心人物與學說剖析

### 一、 朱熹（1130-1200）—— 程朱理學集大成者
- **哲學本體論**：
  - **理在氣先**：宇宙萬物皆由「理」與「氣」構成。「理」是形而上的本體、宇宙規律與道德準則；「氣」是形而下的物質質料。
  - **性即理**：人性的本質就是天地之理，至善無瑕；惡源自氣稟的偏狹與物欲的蔽障。
- **修養與教育工夫：格物窮理**：
  - 「**格物**」：接觸萬事萬物（一草一木皆有理）。
  - 「**窮理**」：窮究事物背後客觀存在的理則。
  - 取向：**外在的、歸納的、客觀的知識累積**。
- **知識論路線**：**道問學**（廣博讀書、考據經典、遵循客觀規範）。
- **知行觀**：**知先行後、行重於知**。
  - 「論先後，知為先；論輕重，行為重。」必須先有正確的道德認知，行動方不致盲目。
- **歷史影響**：編撰《**四書集注**》（大學、中庸、論語、孟子），自元明清三代成為科舉考試官方標準教科書。

---

### 二、 陸九淵（1139-1193）—— 陸王心學創始人
- **哲學本體論**：
  - **心即理**：本心即是天理，宇宙真理不假外求。
  - 名言：「**宇宙便是吾心，吾心即是宇宙。**」、「東海有聖人出焉，此心同也，此理同也；西海有聖人出焉，此心同也，此理同也。」
- **修養與教育工夫：發明本心**：
  - 反對朱熹支離繁瑣的考據讀書，主張直接掃除私欲雜念，讓內心原本光明純粹的本性自然顯現。
  - 取向：**內在的、直覺的、演繹的自省領悟**。
- **知識論路線**：**尊德性**（立大本、切己自反）。
- **歷史名事件**：**鵝湖之會（1175年）**——朱熹與陸九淵在此辯論教育進路，朱熹主「道問學（多讀書）」被評為繁瑣支離；陸九淵主「尊德性（重自省）」被評為近於禪宗。

---

### 三、 王陽明（1472-1529）—— 心學集大成者
- **哲學突破**：
  - 「**心外無物，心外無理，心外做事。**」
  - 經歷「龍場悟道」，頓悟聖人之道，吾性自足，不假外求。
- **核心教育主張**：
  1. **致良知**：
     - 良知是人人天生具備的道德是非判斷力（孟子不學而能、不慮而知的善端）。
     - 「致」是將內在良知實踐擴充於具體人倫事務之中。
  2. **知行合一**：
     - **「知是行之始，行是知之成。」**
     - **「真知即所以為行，不行不足謂之知。」**
     - 反對將知與行割裂為兩截（如看見惡臭立刻掩鼻，掩鼻的瞬間知與行同時完成）。
- **兒童教育主張（《訓蒙大意》）**：
  - 主張順應兒童活潑好動之天性（「大抵童子之情，樂嬉遊而憚拘檢」）。
  - 教育應如「春風化雨」，倡導唱歌、跳舞、習禮，反對以棍棒酷刑約束摧殘童真。

## 程朱理學 vs. 陸王心學 核心維度總對照

| 比較維度 | 程朱理學（[[朱熹]]） | 陸王心學（[[陸九淵]] / [[王陽明]]） |
| :--- | :--- | :--- |
| **核心本體** | **性即理**（理客觀存在於外在萬物） | **心即理**（真理即在自我本心之中） |
| **修養工夫** | **格物窮理**（由外向內，廣泛探索） | **發明本心 / 致良知**（由內向外，反躬自省） |
| **治學進路** | **道問學**（重博覽經典、讀書深思） | **尊德性**（重道德立志、直契本心） |
| **方法論屬性** | **客觀歸納法**（累積漸進） | **直覺演繹法**（頓悟本心） |
| **知行關係** | **知先行後**（知在先，行在後） | **知行合一**（知行並進，行是知之成） |
| **教甄誘答** | 易被批評為「支離割裂、泥古不化」 | 易被批評為「空疏不實、流於狂禪」 |

## 國小教甄歷屆考點與陷阱
- **名言配對必考**：
  - 「格物窮理、道問學、四書集注」➔ 必選 **朱熹**。
  - 「宇宙便是吾心，吾心即是宇宙、發明本心」➔ 必選 **陸九淵**。
  - 「致良知、知行合一、心外無物」➔ 必選 **王陽明**。
- **知行觀高頻陷阱**：
  - 題目若問「知是行之始，行是知之成」，常有人錯選朱熹，**正確答案是王陽明**！
  - 朱熹強調「知先行後」，知是起點、行是歸宿，但兩者是分開的兩個步驟。
