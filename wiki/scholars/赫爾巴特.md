# 赫爾巴特（Johann Friedrich Herbart）

## 一句話定位
> 德國偉大哲學家、心理學家與教育家，**「教育學之父」**與**「心理學之父」**，首創以科學理論奠定現代教育學體系。

---

## 核心主張與理論架構
- **代表著作**：《普通教育學》（General Pedagogy，1806）——標誌著**教育學正式脫離哲學附庸，成為一門獨立的科學體系**。
- **教育學的兩大科學理論基石**：
  1. **倫理學（道德哲學）**：提供教育的**「目的」**（培養道德品格、實現內在自由、完善、仁慈、正義、公平五大道德觀念）。
  2. **心理學**：提供教育的**「方法與途徑」**（了解心靈機制以進行有效教學）。
- **統覺論（Apperception）**：
  - 心靈中既有的經驗觀念群稱為**「統覺團（Apperceptive Mass）」**。
  - 當新觀念進入意識閾限時，必須與統覺團產生互動、比較、同化與吸收，形成更廣泛的認知網絡，學習才算真正發生。
- **多方面興趣（Many-sided Interests）**：
  - 主張教學必須激發兒童廣泛而均衡的興趣，分為兩大範疇六大類：
    - **認識的興趣（對自然的認知）**：
      1. **經驗興趣**（感知客觀事物）。
      2. **思索興趣**（探究因果原理）。
      3. **審美興趣**（鑑賞藝術美感）。
    - **同情的興趣（對人際社會的關懷）**：
      4. **同情興趣**（關懷身邊同伴）。
      5. **社會興趣**（參與群體公共事務）。
      6. **宗教興趣**（體會神聖與宇宙生命歸宿）。
- **赫爾巴特「四段教學法」**（心靈吸收知識的四個進程）：
  1. **明瞭（Clearness / Clarity）**：深入分析個別概念，使概念孤立分明、清晰呈現。
  2. **聯合（Association）**：將新觀念與學生舊有觀念（統覺團）互相連結比較。
  3. **系統（System）**：將聯合後的觀念進行邏輯結構化，形成普遍規律或原理。
  4. **方法（Method）**：將所得的規律應用於新的情境、練習題或實際問題中。
- **赫爾巴特學派「五段教學法」**（由弟子齊勒 Ziller 與萊恩 Rein 發展，成為近代全球小學師範教育的主流）：
  1. **預備（Preparation）**：喚醒學童相關舊經驗（引起動機）。
  2. **提示（Presentation）**：呈現新教材內容。
  3. **比較（Comparison）**：新舊概念比較異同、促進同化。
  4. **概括 / 統整（Generalization）**：歸納出法則、定義或概念。
  5. **應用（Application）**：練習題作答、生活情境遷移驗證。

## 國小教育現場與教學應用
- **引起動機與起點行為確認**：國小課堂教學開始時的「溫故知新」，即是赫爾巴特統覺論與預備階段的具體實踐。
- **結構化直接教學模式**：五段教學法的邏輯步驟，是當今國小各學科（尤其是國語文、數學定理）精熟學習與結構化教學的底層骨架。

## 國小教甄歷屆考點與陷阱
- **核心稱號必考**：
  - **教育學之父** ➔ **赫爾巴特**。
  - **近代教育學之父** ➔ **康門紐斯（Comenius）**。
  - **幼稚教育之父** ➔ **福祿貝爾（Fröbel）**。
  - **國民教育之父** ➔ **裴斯泰洛齊（Pestalozzi）**。
- **教學步驟排列陷阱**：
  - 赫爾巴特四段：**明瞭 ➔ 聯合 ➔ 系統 ➔ 方法**（口訣：**明聯系方**）。
  - 萊恩五段：**預備 ➔ 提示 ➔ 比較 ➔ 概括 ➔ 應用**（口訣：**預提比概應**）。
- **破題關鍵字**：看到「統覺團、多方面興趣、倫理學定目的心理學定方法」必選 **赫爾巴特**！
