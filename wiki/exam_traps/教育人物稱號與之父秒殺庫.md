# 國小教甄「教育人物之父與尊稱」終極秒殺對照庫

## 一句話定位
> 各縣市國小教甄初試教育專業科目每年必出 1~3 題之經典「父稱、尊號、喻稱」全方位防陷阱寶典。

---

## 壹、 「教育之父」系列超高頻秒殺表

| 稱號 / 尊稱 | 正確學者 | 核心出題陷阱與誘答防範 |
| :--- | :--- | :--- |
| **教育學之父** | **[[赫爾巴特\|赫爾巴特（Herbart）]]** | 以心理學與倫理學為基石，著《普通教育學》，使教育學成獨立科學。**（常故意放康門紐斯來誘答！）** |
| **近代教育學之父** | **[[康門紐斯\|康門紐斯（Comenius）]]** | 提出泛智論、著《大教育學》與第一本插畫教科書《世界圖解》。**（注意題目有沒有「近代」二字！）** |
| **國民教育之父<br>小學教育鼻祖<br>孤兒之父** | **[[裴斯泰洛齊\|裴斯泰洛齊（Pestalozzi）]]** | 提出 3H 教學（頭心手），教育心理化，實物教學，《林哈特與葛楚德》。 |
| **幼稚教育之父** | **[[福祿貝爾\|福祿貝爾（Fröbel）]]** | 創辦世界上第一所幼稚園（Kindergarten），發明恩物（Gifts），愛與榜樣。 |
| **自然主義之父<br>教育界的哥白尼** | **[[盧梭\|盧梭（Rousseau）]]** | 主張兒童本位，著《愛彌兒》，消極教育，自然後果懲罰。 |
| **道德哲學之父<br>西方孔子** | **[[蘇格拉底與柏拉圖與亞里斯多德\|蘇格拉底（Socrates）]]** | 產婆法（問答法）、知即德、自認無知、反對智者派收費灌輸。 |
| **平民教育之父（中國）** | **[[蔡元培與近代平民教育家|陶行知]]** | 「生活即教育」、「社會即學校」、「教學做合一」，創辦曉莊師範。 |
| **兒童教育之父 / 活教育之父（中國）** | **[[蔡元培與近代平民教育家|陳鶴琴]]** | 提倡「活教育」理論（大自然、大社會都是活教材），南京鼓樓幼稚園。 |

## 貳、 「心理學之父」系列精準辨析（教甄高誘答熱區）

| 稱號 | 正確學者 | 辨析關鍵字與代表貢獻 |
| :--- | :--- | :--- |
| **科學心理學之父<br>實驗心理學之父** | **[[桑代克與近代教育心理學家|馮德（Wilhelm Wundt）]]** | **1879 年在德國萊比錫大學創立世界第一個心理學實驗室**，使心理學脫離哲學成為獨立科學。 |
| **教育心理學之父** | **[[桑代克與近代教育心理學家|桑代克（Edward Thorndike）]]** | 著《教育心理學》（1903），提出**迷籠實驗、試誤說、學習三大定律（準備律、練習律、效果律）**。 |
| **智力測驗之父** | **[[桑代克與近代教育心理學家|比奈（Alfred Binet）]]** | 1905 年編制世界第一個標準化智力測驗（比西量表），提出「**心理年齡（MA）**」。 |
| **比率智商（IQ）提出者** | **推孟（Terman）與斯騰（Stern）** | 斯騰提出 IQ = (MA / CA) 概念；推孟於史丹福—比奈量表正式確立 IQ = (MA/CA) × 100 公式。 |
| **近代社會學之父** | **韋伯（Max Weber）** | 提出科層體制理論（Bureaucracy）、新教倫理與資本主義精神。 |
| **教育社會學之父** | **[[涂爾幹|涂爾幹（Émile Durkheim）]]** | 提出有機連帶 vs 機械連帶、集體意識、教育是社會化工具。 |

## 參、 經典喻稱與哲學定位秒殺

| 喻稱 / 稱號 | 學者姓名 | 出題脈絡與核心理論 |
| :--- | :--- | :--- |
| **心靈雕刻家隱喻** | **笛卡兒（Descartes）** | 心靈實體說，雕刻家鑿去石料顯現內在本質。 |
| **心靈白板說（Tabula Rasa）** | **[[洛克|洛克（Locke）]]** | 人心如白紙，一切觀念源自後天感覺與反省經驗。 |
| **教育花園與園丁論** | **[[福祿貝爾\|福祿貝爾（Fröbel）]]** | 兒童是種子，心懷神性；教師如園丁順應其天性滋養。 |
| **教育是心靈轉向（走出洞穴）** | **[[蘇格拉底與柏拉圖與亞里斯多德\|柏拉圖（Plato）]]** | 洞穴寓言，由感官現象界轉向永恆理型世界。 |
| **近代科學之父（新工具）** | **培根（Bacon）** | 「知識就是力量」、歸納法、破除四偶像（種族/洞穴/市場/劇場）。 |
| **哲學界哥白尼（批判哲學）** | **[[康德\|康德（Kant）]]** | 調和理性與經驗，「感性無知性則盲，知性無感性則空」。 |
| **教育界的基督** | **[[裴斯泰洛齊\|裴斯泰洛齊（Pestalozzi）]]** | 終身奉獻於貧民孤兒，以慈愛與自我犧牲感化兒童。 |
