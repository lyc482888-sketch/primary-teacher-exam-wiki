# 中國歷代人性論與教育主張全解析（初試高頻題庫）

## 一句話定位
> 中國教育思想史最核心的哲學基石——歷代思想家對「人性本質」的判斷直接決定了「教育功能與方法」的設計。

---

## 歷代人性論流派核心總表

| 人性主張 | 代表思想家 | 核心名言與理論比喻 | 對應教育功能與主張 |
| :--- | :--- | :--- | :--- |
| **性善論** | **[[孔孟荀墨\|孟子]]** | 「人性之善也，猶水之就下也」<br>人人具備惻隱、羞惡、辭讓、是非四端 | **求其放心、存心養性、擴充善端**<br>教育在於引導發揚內在固有良善 |
| **性惡論** | **[[孔孟荀墨\|荀子]]** | 「人之性惡，其善者偽也」<br>「青出於藍」、「蓬生麻中不扶而直」 | **化性起偽、積偽成聖、隆禮重法**<br>教育在於透過外在制度矯正天生惡性 |
| **性無善無惡** | **告子** | 「性，猶湍水也，決諸東方則東流，決諸西方則西流」<br>「食色，性也」 | **引導規範、後天養成**<br>如同治水築堤，善惡全憑後天習慣 |
| **素絲說<br>（環境決定論）** | **[[孔孟荀墨\|墨子]]** | 「染於蒼則蒼，染於黃則黃，所入者變，其色亦變」 | **主動教育、慎選環境、強說人**<br>重視良善環境薰陶與客觀感染力 |
| **性有善有惡** | **世碩、公孫尼子** | 「性有善有惡，引人之善，則善長；引人之惡，則惡長」 | **導善抑惡、養善去惡** |
| **性三品說** | **[[董仲舒]]**<br>韓愈 | **聖人之性**（天生極善，不教自成）<br>**中民之性**（可善可惡，**仰賴王政教化**）<br>**斗筲之性**（下愚冥頑，難教化，賴刑罰約束） | **教育重心在「中民之性」**<br>確立罷黜百家獨尊儒術、設太學之必要 |
| **性二元論<br>（天地之性 vs 氣質之性）** | **張載**<br>[[朱熹與陸九淵與王陽明\|朱熹]] | **天地之性**（天命之性，純然天理，至善）<br>**氣質之性**（受氣候血肉形體所限，有清濁昏明） | **變化氣質、格物窮理、去人欲存天理**<br>教育的功能在於滌除氣質之蔽 |
| **心體無善無惡<br>（陽明四句教）** | **[[朱熹與陸九淵與王陽明\|王陽明]]** | **「無善無惡心之體，有善有惡意之動，<br>知善知惡是良知，為善去惡是格物。」** | **致良知、知行合一**<br>隨時隨事在心上做工夫，拔本塞源 |
| **性日生日成** | **王夫之（船山）** | 「性非生而具備固定不變者，而是隨生命成長日日生成」 | **重視終身教化與動態實踐修養** |

## 國小教甄選擇題超高頻題眼剖析

### 陷阱 1：董仲舒「性三品說」中，教育主要針對哪一品？
- **選項陷阱**：常有考生誤以為教育要感化「斗筲之性」或讚美「聖人之性」。
- **破題密碼**：董仲舒明確指出，聖人之性不教而能，斗筲之性刑戮難移，**教育真正的對象是數量最龐大的「中民之性」**！必須透過國家學校與禮樂教化，方能轉化成善。

### 陷阱 2：告子 vs. 墨子 的比喻區別
- **告子** ➔ **「湍水之喻」**（水決東則東流，決西則西流，無分於善不善）。
- **墨子** ➔ **「素絲之喻」**（染於蒼則蒼，染於黃則黃）。

### 陷阱 3：王陽明「四句教」對應關係
- **心之體** ➔ 無善無惡（超脫相對善惡的超越本體）。
- **意之動** ➔ 有善有惡（動念有了偏向）。
- **良知** ➔ 知善知惡（先天的道德是非指針）。
- **格物** ➔ 為善去惡（具體端正心念與力行）。
